# 教学工具的两种标准模式：课堂对垒 / 自由作答

> 本规格适用于**课堂点子铺旗下所有教学工具**，不限科目年级。
> 新工具开工前先读这份，不要每个工具各自发明一套模式与流程。
> 来源：2026-08-13 与卢老师讨论 `tahun1-mt-masa`（时刻大对决）时确立。

## 为什么要标准化这两种模式

一个工具如果只做双人对战，它就**只能在老师带全班的时候用**；只做个人练习，它就**进不了课堂**。
这两种模式覆盖两个完全不同的使用场景，而且共用同一套题库、判分与难度设定，多做一个模式的边际成本很低，
但工具的可用场合直接翻倍。

所以：**除非玩法本质上不可能单人玩（例如体感对抗、抢按铃），否则新工具两种模式都要做。**

---

## 模式一：课堂对垒（Duel Kelas）

**场景**：老师带全班，投影或触控一体机，两个学生上台对战，其余同学观战。

### 必须有

1. **接 kelasku 班级名单**（网址 `?code=`），老师不必手打名字。
   读不到名单时要能退回手动输入，不可以因此坏掉。

2. **自动抽签**决定这一局谁对谁：
   - **不重复**：抽过的学生进「已上场」池，同一轮内不会再被抽到。
   - **用完才重来**：全班都上场过一轮后，池子才清空重新开始。
     ⚠️ 这一条是重点——单纯随机抽会造成有的孩子上场三次、有的一次都没轮到，
     「不重复 + 用完重来」才保证每个孩子都轮得到，这是课堂公平性问题，不是技术偏好。
   - **两个班级时**（`?code=A,B` 解析出两个班）：**一边一个班**，A 班抽一人 vs B 班抽一人，
     各班各自维护自己的已上场池。
   - **三个班以上**：按顺序两两轮转配对（班1vs班2、班3vs班4、班1vs班3…）。

3. **抽签要有仪式感**：名字要滚动/转盘一下再定格，不要瞬间跳出结果。
   这不是装饰——课堂气氛与学生的期待感就是靠这几秒建立的。

4. **老师可以介入**：抽到的学生缺席或不适合上场时，要能「重抽这一位」或手动指定。

5. **一局结束后可以直接「下一对」**，接着抽下一组，不用退回设定页重设一次。

### 不该有

- 不要求登录。
- 不要在对战进行中要求老师做任何设定。

## 模式二：自由作答（Latihan Sendiri）

**场景**：学生自己一个人练习——电脑室、家里、或课堂上的个人练习时间。

### 必须有

1. 一个人独立完成，没有对手、没有抢答压力。
2. **成绩要记录得比对垒模式细**：答对几题 / 共几题、**用了多少时间**。
   对垒模式比的是「谁先」，自由作答比的是「自己做得多好、多快」。
3. 可以从班级名单选自己的名字，也可以手动输入。
4. 成绩进排行榜。

---

## 两种模式共用的部分

- 同一套题库、判分逻辑、难度设定与辅助开关。
- 模式选择放在**开始页最上方、一眼可见**，不要藏在设定里。

## ⚠️ 排行榜必须依模式分开

对垒模式有抢答压力、题数由老师定；自由作答可以慢慢想、还会计时。
**两者的成绩不可比，不能混在同一张榜上。**

实作上：工具专属的分数表要有 `mode` 栏位（`'duel'` / `'solo'`），
「同一个人只留最好一局」的合并键是 `(play_code, name, mode)`，排行榜画面要能切换模式。

「最好一局」的判定建议：
- 对垒：先比正确率，正确率相同再比题数多的那局。
- 自由作答：先比正确率，正确率相同再比**用时短**的那局。

---

## 命名与登记

- 分数表命名照既有约定：`{完整slug用底线连接}_scores`（例如 `tahun1_mt_masa_scores`）。
- 上架到 Hub 时，`prep` 栏位要写清楚这个工具支持哪些模式、各需要什么条件
  （例如「课堂对垒需要班级代码；自由作答不需要」）。
