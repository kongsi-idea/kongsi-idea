## 5 个语文技能模组摘要（四年级）

### 1.0 听说技能
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 1.1 进行口语交际 | 1.1.1 **理解别人的说话**，并敢于说出自己的感受（较三年级更强调理解与感受表达）；1.1.2 正确应用疑问代词，语句完整问题清楚 |
| 1.2 聆听口语和书面语 | 1.2.1 耐心聆听，边听边记边想，**抓住内容要点**；1.2.2 **正确把握中心思想**，抓住内容要点（新增"中心思想"概念） |
| 1.3 进行口头表达 | 1.3.1 讲述事情并**说出自己的看法**（新增表达个人观点）；1.3.2 说明活动步骤/解决方法，层次分明 |

### 2.0 阅读技能
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 2.1 阅读与理解教材 | 2.1.1 借助**工具书**（较三年级"字典"扩大为工具书）认识汉字词语句段篇内容 |
| 2.2 朗读教材，感悟其内容 | 2.2.1 语音正确字句完整，**情感自然**（教材：寓言/童话/神话/民间故事/记叙文） |

### 3.0 书写技能
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 3.1 应用铅笔写字 | 3.1.1 书写正楷，**做到字体规范、有一定书写速度**（较三年级新增速度要求） |
| 3.2 培养书面表达能力 | 3.2.1 **习写段落**进行练笔，写出人物或事物局部特点（较三年级"写话"提升为"段落"）；3.2.2 习写日记，尝试书写所见所感；3.2.3 **进行书面表达（作文）**，不拘形式，内容具体思想健康条理清楚（首次出现"作文"层级，含记叙性/说明性作文） |

### 4.0 趣味语文
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 4.1 进行各类语文游戏 | 4.1.1 以有趣形式积累扩展词汇，操练语音 |
| 4.2 背诵古诗 | 4.2.1 背诵古诗十首 |
| 4.3 诵读和演绎教材 | 4.3.1 语音正确、语调恰当、生动自然有感情 |
| 4.4 分享阅读心得 | 4.4.1 针对所阅读材料，找出话题与人分享 |
| 4.5 习写毛笔字 | 4.5.1 **使用毛笔仿影**名家楷书字帖（较三年级"描红"进阶为"仿影"），间架结构匀称 |

### 5.0 语文基础知识
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 5.1 掌握汉字基本知识 | 5.1.1 汉字演变基本知识，加强识记 |
| 5.2 学会汉语拼音 | 5.2.1 正确读出"一""不"的变调**和"啊"的音变**（新增音变知识） |
| 5.3 认识各类词语 | 5.3.1 认识量词、近似字、多音字 |
| 5.4 认识不同类型的句子 | 5.4.1 认识不同类型句子，了解关联词语在句中作用并正确使用 |
| 5.5 认识各种标点符号 | 5.5.1 **分号、着重号、连接号**的使用（较三年级括号书名号间隔号更进阶） |
| **5.6 认识基本的修辞手法**（四年级新增） | 5.6.1 认识修辞手法（比喻、夸张、比拟、反复、引用等），体会其在文章表达中的效果 |

> 备注：趣味语文、语文基础知识均不另设评价标准，课堂评价依语文技能评价标准进行。

## 与中低年级对照的年级递进重点（备忘）
- 四年级是「高年段」起点，书面表达从"写话/段落"正式提升到"作文"层级（3.2.3）
- 修辞手法（5.6）与关联词语运用首次要求"正确使用"而非仅"了解"
- 毛笔字从"描红"（三年级）进阶为"仿影"（四年级）
- 阅读工具从"字典"扩展为"工具书"
