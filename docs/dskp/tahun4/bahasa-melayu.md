## 总论重点

**课程宗旨**：让学生具备语言能力，能沟通以满足自身需求、获取知识技能资讯价值与想法，并在日常生活中建立社会联系。

**总体目标（8 项，节录）**：正确回应指示/传达/询问；说故事、讨论、有礼貌地发表意见；正确发音语调朗读理解并推理显性隐性讯息、广泛阅读以丰富词汇培养阅读兴趣；笔记/书写/听写以运用得体语言；创作多种文体写作、编辑、写评论；欣赏文学作品语言之美；正确使用语言系统于说读写。

**四年级具体目标（21 项，节录重点）**：听辨发音、理解并回应话语；听懂并批判地回答；有礼貌地就评价事项给出理由；批判创意地就比较信息作说明；回答各类提问；正确发音适当语调说故事/讲述事情；正确发音适当语调朗读；阅读理解图表材料以形成画面；阅读分析文学与非文学课文内容；以适当风格朗读文学非文学作品；阅读辨识解释非文学文学材料内容并展示；连体字抄句；批判创意地写句子段落、写理解答案并分析记录信息；听写句子段落；起草创作想象性/描述性文章并编辑润色；讲述含谚语的故事；诵读解释诗歌 Sajak 含义；唱歌解释歌词；引导式改编展示诗歌/故事/歌词；认识日常物品上的爪夷文（Jawi）书写；理解运用名词/动词/形容词/虚词/词缀词/复合词/叠词；理解构造单句复句/陈述句疑问句/主动句/常序倒序句。

**KSSR 六大支柱**：沟通；灵性态度价值观；人文；自我技能；体能与美育；科学与工艺。

**21世纪学生素质（表1）**：坚毅、善沟通、思考者、团队精神、求知欲强、有原则、掌握信息、有爱心/关怀、爱国——内容与三年级版本一致。

**高层次思维 KBAT（表2，四个思维层次）**：应用、分析、评价、创造——定义与三年级版本一致。

**教学策略（5P 概念）**：贯穿融合、渗透、增润、补救、评估；模组式教学法（听说读写四技能＋语文欣赏＋语法模组化）、寓教于乐；主题式教学法（12大主题：家庭、社会性、健康与卫生、安全、团结、文化艺术与美学、身份认同与爱国精神、科学技术与创新、环境永续、农牧业、经济企业与理财管理、诚信）；另提及解决问题学习、专题学习、探究学习、合作学习、以学生为中心学习、情境学习、户外学习、建构主义学习、未来研究法、自主学习、精熟学习（需掌握80%精熟度方可进入下一单元）。

**跨课程元素 EMK（本文件列 10 项，与三年级版本项目相近但顺序及个别项目略有调整）**：语言、科学与工艺、资讯与通讯工艺 TMK、道德价值观、爱国精神、创造力与创新、企业家精神、**理财教育**（可直接融入"钱币 Wang"课题如单利复利计算，或渗透式融入其他课题）、**道路安全教育（Pendidikan Keselamatan Jalan Raya，四年级新增项目）**、全球永续（含永续生产消费/全球公民/团结三元素）。

**课堂评估 Pentaksiran Bilik Darjah（PBD，四年级起用词由 Pentaksiran Sekolah 改为 PBD）**：形成性＋总结性；须运用多元评估方法（观察、口试、笔试）与策略，兼顾不同知识技能层次，依 Standard Pembelajaran 与 Standard Prestasi 评定，并采取补救/巩固跟进行动。整体掌握程度（Tahap Penguasaan Keseluruhan）共 6 级：非常有限、有限、满意、良好、非常良好、卓越（详见下方共通结构）。听说/阅读/写作三项技能各有独立表现标准，语文欣赏与语法方面不设独立表现标准（但可用以评估上述三项技能）。

## 5 个单元摘要

### 1.0 听说技能 Kemahiran Mendengar dan Bertutur（第29–32页）

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 在正式与非正式情境沟通中听并回应 | 听辨发音并在非正式情境复述所听内容；听懂并回应非正式情境话语；听懂并批判地回答提问 |
| 1.2 说话以传达信息与想法 | 有礼貌地就事物作评价并给理由；批判创意地说明比较显性与隐性信息；回答所提出的问题 |
| 1.3 以正确发音语调讲述所听/所看/所读内容 | 以适当发音语调讲故事；以适当发音语调讲述所观看内容 |

**表现标准 1–6**：听辨发音回应话语、沟通给出理由陈述信息、回答各类提问、以正确发音语调有礼貌地讲述事情——从「非常有限」逐级进阶到「非常详尽、稳定并成为楷模」。

### 2.0 阅读技能 Kemahiran Membaca（第33–34页）

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 基础阅读与理解 | 以正确发音适当语调阅读理解课文段落 |
| 2.2 阅读理解并推理多媒体材料 | 阅读理解多媒体图表材料以形成画面 |
| 2.3 阅读与欣赏文学及非文学作品 | 阅读分析文学与非文学课文内容；以适当风格朗读文学与非文学作品 |

**表现标准 1–6**：阅读理解发音语调，理解分析文学非文学作品内容并以适当风格展示——从「非常有限」到「非常详尽、稳定并成为楷模」。

### 3.0 写作技能 Kemahiran Menulis（第35–37页）

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 基础写作 | 以连体字机械式书写句子 |
| 3.2 写出有意义的词语短语句子 | 依多媒体材料构思书写句子段落；批判创意地写出集中式/发散式理解题答案；分析记录信息；听写段落中的句子 |
| 3.3 完成写作 | 起草并创作想象性、描述性文章；从拼写标点、词缀使用角度编辑润色句子 |

**表现标准 1–6**：构思书写句子、听写、记录信息、创作想象性描述性文章并编辑润色——从「非常有限」到「非常详尽、稳定并成为楷模」。

### 4.0 语文欣赏方面 Aspek Seni Bahasa（第38–39页，不设独立表现标准，不予评估）

| 内容标准 | 学习标准要点 |
|---|---|
| 4.1 运用文学作品语言之美与得体 | 讲故事并说出含谚语的对话 |
| 4.2 欣赏文学作品语言之美与得体 | 诵读解释诗歌 Sajak 含义；依民谣曲调唱歌并解释歌词含义 |
| 4.3 创作并展示融入语言美感得体的文学作品 | 引导式改编诗歌并创意展示；引导式改编故事并创意展示；改编歌词并创意展示 |
| 4.4 认识并欣赏爪夷文作为民族文化遗产 | 认识日常生活物品（钞票、邮票、徽章等）上的爪夷文；透过日常物品上的词语展示爪夷文书写 |

> 备注：语文欣赏方面用于支持语言技能教学，但**明确不予评估**；SJK 是否实施爪夷文教学以选择方式进行，须经家协、家长及学生同意。

### 5.0 语法方面 Aspek Tatabahasa（第40–42页，不设独立表现标准）

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 理解并依语境运用词类 | 名词类（在非正式情境中用普通/专有名词、代词、量词）；动词类（主动及物/不及物、被动动词）；形容词类（方式/距离/度量/感受/感官）；虚词类（连词、介词、否定词、数词） |
| 5.2 理解并依语境运用构词 | 词缀词（前缀、后缀、附加缀 apitan）；复合词（自由复合词、固定复合词）；叠词（全叠、半叠） |
| 5.3 理解并依语境造句 | 依语境理解构造各类单句复句；陈述句、疑问句；主动句；常序句与倒序句 |

> 备注：语法方面的评估可结合听说/阅读/写作技能视教学适宜性一并进行。

## 表现标准共通结构（备忘）
听说、阅读、写作三大技能各自的 6 级表现标准（Tahap Penguasaan）在四年级文件中直接以标签形式呈现（与三年级文件仅用编号+叙述略有不同，措辞更统一），进阶逻辑如下：

1. **非常有限（Sangat Terhad）**——所述技能表现程度非常薄弱、非常有限
2. **有限（Terhad）**——表现程度薄弱、有限
3. **满意（Memuaskan）**——表现程度中等
4. **良好（Baik）**——表现程度良好
5. **非常良好（Sangat Baik）**——表现程度高，能清楚详细表达
6. **卓越（Cemerlang）**——表现卓越且稳定，能清楚详细系统表达、批判创意创新思维、自信有效沟通、自主学习并成为其他学生的楷模

三项技能（听说/阅读/写作）各自的具体措辞略有差异，但整体上都遵循「非常有限 → 有限 → 满意 → 良好 → 非常良好 → 卓越」六级架构。语文欣赏方面与语法方面不设独立表现标准，语文欣赏方面且明确不予评估。

## 与三年级版本的主要差异提示（供备课对照）
- 三年级用词 "Pentaksiran Sekolah"，四年级起改称 "Pentaksiran Bilik Darjah"（PBD）
- 三年级整体表现等级标签在文中未完整显示第5–6级名称（第4级称"Baik"），四年级则明确标示6级标签为 Sangat Terhad/Terhad/Memuaskan/Baik/Sangat Baik/Cemerlang
- 四年级语文欣赏方面新增「认识爪夷文」内容标准（4.4），且明确该项以学校自愿选择方式实施
- 四年级跨课程元素新增「道路安全教育」独立项目，三年级文件未见此项
- 四年级语法方面新增词缀"apitan"（附加缀）及扩充形容词类别（新增"距离、感受"）
