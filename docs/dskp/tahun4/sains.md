## 10 个课题摘要（四年级）

### 科学技能
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 1.1 科学程序技能 | 定性观察；依相同特征比较分类；正确方法测量；作合理解释/推断；预测；沟通记录呈现；依时间排列事件；从资料诠释见解 |

### 生命科学
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 2.1 人类的呼吸 | 确认呼吸涉及的器官；讲述空气流程与气体转换；分辨吸气呼气时氧气二氧化碳含量；讲述胸腔起伏；概括呼吸率因活动种类而异 |
| 2.2 排泄与排遗 | 说出排泄排遗定义；确认排泄器官和排泄物；配对排泄器官与排泄物；推论排泄排遗的重要性 |
| 2.3 人类对外来刺激作出反应 | 说出感官受刺激时的反应；解释举例日常生活反应例子（闭眼/缩手/发抖）；推断反应的重要性；讲述影响反应的习惯 |
| 3.1 动物的呼吸器官 | 确认动物呼吸器官；依呼吸器官分类；概括有些动物拥有超过一个呼吸器官 |
| 3.2 脊椎动物 | 说出脊椎/无脊椎动物定义；举例；依专有特征分类（哺乳类/爬行类/两栖类/鸟类/鱼类） |
| 4.1 植物对外来刺激作出的反应 | 观察说出植物对刺激的反应部位；联系植物部分与反应；总结反应部位（研究法） |
| 4.2 光合作用 | 说出光合作用定义；列出所需原料；观察说出产物（淀粉/氧气）；推论光合作用对生物的重要性 |

### 物理科学
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 5.1 光沿着直线传播 | 说出光沿直线传播；比较透明/半透明/不透明体阻挡时形成的影子；测试影响影子大小形状的因素 |
| 5.2 光的反射 | 说出光可被反射；概括生活中光反射原理应用（潜望镜/镜子）；绘画镜子反射光的射线图 |
| 5.3 光的折射 | 观察说出光的折射；举例说明（硬币在水中位置）；讲述彩虹的形成 |
| 6.1 声音 | 说出声音由振动产生；讲述声音向四面八方传播；举例声音被反射（回声/声纳/超音波）；讲述乐音噪音；解决声音污染问题 |
| 7.1 能的来源和能的形式 | 说出能的定义；观察讲述能的来源（太阳能/热能/化学能/电能/动能/声能/势能/光能/核能）；解释举例能的形式转换；概括能不可被创造消灭只能转换 |
| 7.2 可更新能源和不可更新能源 | 观察解释举例两类能源；说出明智用能的重要性；推论节约能源措施对永续性的重要性 |

### 材料科学
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 8.1 材料的来源 | 举例物体材料来源（植物/动物/岩石/石油）；依来源分类物体 |
| 8.2 材料的性质 | 讲述材料性质；应用性质知识创造物品；推论创造物品时材料的选择 |

### 地球与宇宙
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 9.1 地球的地心引力 | 观察讲述地心引力；概括地球物体固定在原位 |
| 9.2 地球的自转与公转 | 说出地球自转同时公转；讲述自转产生的现象；讲述自转公转的方向与所需时间 |

### 工艺
| 内容标准 | 四年级学习标准要点 |
|---|---|
| 10.1 杠杆 | 确认杠杆阻力点支点动力点；概括阻力点离支点距离与所需力之间的关系 |
| 10.2 简单机械和复杂机械 | 解释举例简单机械种类用处；使用两个以上简单机械解决问题；总结复杂机械定义 |

## 与低中年级对照的年级递进重点（备忘）
- 生命科学从"外部结构/习性"（一至三年级）深化为"体内系统运作"（呼吸系统/排泄系统/光合作用），是重要的抽象化转折点
- 物理科学首次系统涉及光学（反射/折射）、声学、能量转换等偏理论概念
- 机械课题从三年级的"滑轮（单一简单机械）"扩展为"杠杆＋简单机械与复杂机械的组合关系"
