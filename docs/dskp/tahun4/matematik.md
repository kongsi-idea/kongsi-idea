## 8 个学习单元摘要（四年级起「整数」与「基本运算」合并为单元1，「坐标」与「比与比例」合并为单元7）

### 1.0 数与运算 — 整数与运算（第32–35页）★整数与基本运算首次合并
**目标**：认识应用100000以内整数／学习整数与基本运算时用正确数学语言／认识应用基本运算概念程序／解答相关应用题／推理联系表示沟通使用工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 数值 | 讲述100000以内数目（读/说/写）；确定数值（数位数值分析、比较、顺逆序排列/完成数列）；笔记强调正确读法（如12425读作一万二千四百二十五）及4500亦可读作四十五百 |
| 1.2 偶数与奇数 | 讲述特征；进行分类 |
| 1.3 估算 | 依参照物估算并确定合理性 |
| 1.4 近似值 | 找出整数至万位的近似值（可涉及钱币和度量衡） |
| 1.5 数列 | 顺逆序一至十个、百个、千个、万个排列规律数列（涉及至6个数目） |
| 1.6 100000以内的基本运算 | 至4数加法；两数减法；三数连减法；五位数以内与二位数/100/1000的乘法（积100000内）；除法 |
| 1.7 混合运算 | 加减混合运算；乘除混合运算（从不进位不借位开始） |
| 1.8 未知数的应用 | 确定加法/减法算式中未知数值（限一个未知数，用字母表示） |
| 1.9 解决问题 | 整数、加减混合运算、乘除混合运算相关应用题；涉及未知数的加减应用题 |

表现标准 1–6：讲述数目/读算式 → 解说数值/运算步骤 → 确定数值(估算近似值)/完成算式判断合理性/解未知数算式 → 常规问题（涉及未知数）→ 多策略常规问题 → 创意非常规问题。

### 2.0 数与运算 — 分数、小数与百分比（第36–39页）★首次出现带分数四则运算、分数分母可大于10
**目标**：联系分数小数百分比与日常生活／解答相关应用题／推理联系表示探究沟通工艺理解概念。

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 分数 | 假分数与带分数互换；至三数加法（真分数、整数、带分数）；两数/三数连减法；加减混合运算；确定真分数带分数在某数量中的值（强调「的」的概念，笔记：和/差的分母可大于10） |
| 2.2 小数 | 至三个数至三位小数的加减法；小数与一位数/10/100/1000的乘法（积至三位小数）/除法（商至三位小数） |
| 2.3 百分比 | 分数与百分比互换；计算某数量的百分比（用百格图） |
| 2.4 解决问题 | 分数小数百分比相关应用题 |

表现标准 1–6：讲述假分数带分数 → 假带分数互换 → 解答整数真分数带分数加减混合运算 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 3.0 数与运算 — 钱币（第40–43页）★首次出现理财预算/付款工具/世界主要国家货币
**目标**：钱币与日常生活联系／日常应用钱币／推理探究钱财使用／钱财沟通联系解决问题／**塑造并实践企业家精神**。

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 钱币的基本运算 | 至三个RM100000以内币值加法/减法；币值与至二位数乘法（积RM100000内）/除法 |
| 3.2 钱币的混合运算 | RM100000以内加减混合运算；乘除混合运算 |
| 3.3 理财 | 计划天/周/月财务预算达短期目标；记录储蓄开支；解说收存记录的需要 |
| 3.4 理财决策的责任 | 解说财务决策影响；依需要需求优先做决策；分析理财资料做决策 |
| 3.5 外币 | 认识世界主要国家货币；讲述RM1与其兑换率 |
| 3.6 付款工具 | 认识现金/电子付款系统/付款卡等各种付款工具；解说交易应用 |
| 3.7 解决问题 | RM100000以内基本运算与混合运算相关应用题 |

表现标准 1–6：认识世界货币汇率 → 解说记录储蓄开支需要 → 完成钱币算式判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

> 备课提示：四年级钱币单元视野从「东盟货币」（三年级）扩大到「世界主要国家货币」，并首次系统教「理财决策责任」与「付款工具（含电子支付/卡）」，是理财素养与数位支付意识教育的关键单元。

### 4.0 测量与几何 — 时间与时刻（第47–50页）★首次引入24时计时法
**目标**：有效利用时间／解答相关应用题／推理联系表示工艺理解概念／沟通建构清楚描述情境。

| 内容标准 | 学习标准要点 |
|---|---|
| 4.1 12时计时法和24时计时法 | 认识两者关系（巩固12时制，介绍24时制） |
| 4.2 相隔时间 | 确定24小时内涉及小时与分钟的时间 |
| 4.3 估算时间 | 依参照物估算涉及小时分钟的时间（须以真实时间证明） |
| 4.4 时间单位之间的关系 | 讲述千禧/世纪/年代/年关系；时和天、天和星期、月和年、年年代世纪换算 |
| 4.5 时间的基本运算 | 至三个时间单位加减法；与至二位数的乘除法 |
| 4.6 解答问题 | 时间相关日常应用题 |

表现标准 1–6：讲述时间单位关系 → 解说算式步骤 → 确认合理性并完成算式 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 5.0 测量与几何 — 度量衡（第51–54页）★首次引入毫米/公里、公英制单位对照
**目标**：用实物建构概念并应用／解答相关应用题／推理联系表示探究沟通工艺理解概念。

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 长度 | 认识毫米/公里；毫米厘米、米公里单位关系与换算；毫米测量物体；公里估算距离；至三单位加减法；与一位数乘除法（笔记：介绍公制分米/十米、英制英寸/英尺/码/英里） |
| 5.2 质量 | 克公斤加减混合运算、乘除混合运算（笔记：介绍公制毫克/吨、英制磅/盎司、其他单位两/斤） |
| 5.3 液体的体积 | 毫升升加减混合运算、乘除混合运算（笔记：介绍英制加仑/夸脱/品脱） |
| 5.4 解决问题 | 度量衡相关应用题 |

表现标准 1–6：讲述单位间关系 → 解说相关单位 → 确认合理性完成算式 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 6.0 测量与几何 — 空间（第56–58页）★首次引入角度/平行垂直线/周长面积公式/体积公式
**目标**：解答相关应用题／通过多边形组成图形珍视鉴赏数学之美／推理联系表示沟通工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 6.1 角度 | 认识说出正方形/长方形/三角形的直角、锐角、钝角（笔记：介绍非等腰/等腰/等边/直角三角形） |
| 6.2 平行线和垂直线 | 认识说出并画出平行线垂直线 |
| 6.3 周长和面积 | 确定至八边多边形周长；用一平方单位方格与公式确定正方形/长方形/直角三角形/等边三角形/等腰三角形面积 |
| 6.4 立体的体积 | 用一立方单位立方体与公式确定正方体长方体体积 |
| 6.5 解决问题 | 空间相关应用题 |

表现标准 1–6：认识角/确认平行垂直线 → 讲述特征及周长面积体积公式含义 → 画平行垂直线/计算周长面积体积 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 7.0 联系与代数 — 坐标，比与比例（第62–64页）★首次将坐标与比例合并、新增归一法
**目标**：解答坐标比与比例相关应用题／珍视鉴赏数学之美／做决定提意见解释日常情境／推理联系表示沟通工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 7.1 第一象限的坐标 | 认识x轴y轴原点(0)；确定第一象限某点坐标或反之（强调坐标(x,y)与原点(0,0)写法） |
| 7.2 比 | 以1:1至1:10、1:100、1:1000表示两数量之比（强调正确写法、贴近生活情境） |
| 7.3 比例 | 以归一法找出某值 |
| 7.4 解决问题 | 坐标、比与比例相关应用题 |

表现标准 1–6：讲述x轴y轴原点/符号归一法含义 → 解说读坐标标点/依比确定值/比较单位值 → 读坐标标点/依比确定值/归一法找值 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 8.0 统计与概率 — 数据处理（第69–70页）★首次要求「建构」统计图（非只读取）
**目标**：掌握从象形统计图和条形统计图获取资料的技能／解答相关应用题／作决策提想法解说日常情境／推理联系表示沟通工艺理解应用数据处理。

| 内容标准 | 学习标准要点 |
|---|---|
| 8.1 象形统计图和条形统计图 | 根据非分组数据建构象形统计图和条形统计图；分析所建构的图（笔记：强调正确建构条形统计图方法；活动建议：含软件建构） |
| 8.2 解决问题 | 数据处理相关应用题 |

表现标准 1–6：读取象形/条形统计图资料 → 解说建构步骤 → 建构并分析统计图 → 常规问题 → 多策略常规问题 → 创意非常规问题。

## 各单元表现标准共通结构（备忘）
与一至三年级一致的六级进阶逻辑：
1. 讲述/读出基本内容
2. 解说步骤/含义（初步操作）
3. 确认合理性/完成算式/画图/建构（含验证意识）
4. 解答日常生活常规问题（单一策略）
5. 运用各种策略解答常规问题
6. 以创意创新方式解答**非常规**问题
