## 9 个学习单元摘要（三年级比一/二年级多出「坐标」独立成为第8单元）

### 1.0 数与运算 — 10000 以内的整数（第32–34页）
**目标**：认识应用10000以内整数／解答相关应用题／推理联系表示沟通使用工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 数值 | 读/说出10000以内数目、数字文字配对；确定数值（展示、配对、比较、顺逆序排列）；笔记强调数目须按正确读法（如4513读作四千五百一十三非四五一三） |
| 1.2 写出数目 | 以数字和文字写出 |
| 1.3 数列 | 顺逆序一个一个至十个十个、百个百个、千个千个地数；完成任何数列 |
| 1.4 数位 | 讲述数位数值；依数位数值分析任何数目 |
| 1.5 估算 | 依参考物合理估算（大约/少于/多于），需以真实数量证实 |
| 1.6 近似值 | 找出整数至千位的近似值 |
| 1.7 有规律的数列 | 确认/完成顺逆序一至十个、百个、千个规律数列（可涉及至6个数目） |
| 1.8 解决问题 | 10000以内整数应用题 |

表现标准 1–6：讲述数目 → 说明数值 → 确定排序/估算近似值/完成数列 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 2.0 数与运算 — 基本运算（第35–38页）
**目标**：认识应用基本运算概念程序／解答应用题／正确数学言语／推理联系表示沟通工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 加法（10000以内） | 两数加法算式、三数连加法算式 |
| 2.2 减法（10000以内） | 两数减法算式、三数连减法算式 |
| 2.3 乘法（10000以内） | 四位数以内与一位数、10、100、1000的乘法，积至10000 |
| 2.4 除法（10000以内） | 与一位数、10、100、1000的除法 |
| 2.5 加减混合运算 | 10000以内加减混合运算（不进位） |
| 2.6 使用未知数 | 确认基本运算算式中的未知数；以算式表示情境（限一个运算法） |
| 2.7 解决问题 | 根据算式编写故事；解答日常加减混合运算应用题 |

表现标准 1–6：读算式 → 解说运算程序 → 完成算式判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 3.0 数与运算 — 分数、小数与百分比（第39–43页）★三年级起新增百分比
**目标**：联系分数小数百分比与日常生活／解答相关应用题／推理联系表示探究沟通工艺理解概念。

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 分数 | 确认真分数为组合一部分；讲述分母至10的等值分数；化最简分数；讲述百分数；两真分数加减法（同分母、分母2与4/6/8/10、3与6/9、5与10、4与8）；确认假分数带分数 |
| 3.2 小数 | 数字文字讲述0.01–0.99；百格图展示小数；比较两小数（至两位小数）；两位小数加减法（和至0.99） |
| 3.3 百分比 | 说出百分比；认识百分号；百格图展示百分比；写出1%至100% |
| 3.4 分数、小数和百分比之间的关系 | 三者互相转换表示（涉及0.1至0.99小数） |
| 3.5 解决问题 | 依算式编写故事；解答分数小数百分比应用题 |

表现标准 1–6：讲述真假带分数/小数/百分比 → 解说 → 比较小数值/真分数加减/小数加减并判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 4.0 数与运算 — 钱币（第44–47页）★三年级起扩大至RM10000、新增外币认识
**目标**：钱币与日常生活联系／应用理财教育／推理探究钱财使用／钱财沟通联系解决问题／**塑造并实践企业家精神**。

| 内容标准 | 学习标准要点 |
|---|---|
| 4.1 钱币的加法 | RM10000以内两个币值加法、三个币值连加法 |
| 4.2 钱币的减法 | RM10000以内两个币值减法、三个币值连减法 |
| 4.3 钱币的加减混合运算 | RM10000以内加减混合运算 |
| 4.4 钱币的乘法 | 积在RM10000以内，币值与一位数/10/100/1000的乘法 |
| 4.5 钱币的除法 | RM10000以内，币值与一位数/10/100/1000的除法 |
| 4.6 认识外币 | 认识东盟各国货币；说出当前令吉与外币兑换率 |
| 4.7 储蓄与投资 | 说明需求需要是储蓄消费基础；说明储蓄投资需要（笔记定义需求/需要/投资/乐捐） |
| 4.8 解决问题 | 依钱币算式编写故事；解答加减混合运算相关应用题 |

表现标准 1–6：认识东盟货币汇率 → 说明储蓄投资目的 → 完成钱币算式判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

> 备课提示：三年级钱币单元首次引入「外币认识（东盟货币、汇率）」与「储蓄/投资/乐捐」概念区分，是理财教育与企业家精神跨课程元素融合最集中的单元，教案可设计模拟兑换、乐捐情境活动。

### 5.0 测量与几何 — 时间与时刻（第48–52页）★三年级起扩展至加减乘除四则运算
**目标**：有效利用时间／解答相关应用题／推理联系表示工艺理解概念／沟通建构清楚描述情境。

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 时刻上的时与分 | 从活动时间表读出获取资料；读出记录活动前中后时刻 |
| 5.2 时间单位之间的关系 | 星期与天、年与月、分钟与秒关系；小时与分钟、分钟与秒换算 |
| 5.3 认识日历 | 从公历（阳历）读出获取资料 |
| 5.4 时间的加法 | 至三个时间单位加法（小时/分钟/秒及复合单位） |
| 5.5 时间的减法 | 同上式减法 |
| 5.6 时间的加减混合运算 | 涉及以上各单位 |
| 5.7 时间的乘法 | 时间与一位数的乘法 |
| 5.8 时间的除法 | 时间与一位数的除法 |
| 5.9 解答问题 | 依算式编写故事；解答日常应用题 |

表现标准 1–6：读时刻/日历 → 解说时间表资料 → 记录活动/完成时间算式 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 6.0 测量与几何 — 度量衡（第53–56页）★三年级起加入乘除运算
**目标**：用实物建构概念并应用／解答相关应用题／推理联系表示探究沟通工艺理解概念。

| 内容标准 | 学习标准要点 |
|---|---|
| 6.1 长度 | 米/厘米单位换算；至三个长度加法/减法；与一位数的乘法/除法 |
| 6.2 质量 | 公斤/克单位换算；至三个质量加法/减法；与一位数的乘法/除法 |
| 6.3 液体的体积 | 升/毫升单位换算；至三个体积加法/减法；与一位数的乘法/除法 |
| 6.4 解决问题 | 依算式编写故事；解答度量衡相关应用题 |

表现标准 1–6：讲述单位关系 → 解说相关单位 → 完成算式 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 7.0 测量与几何 — 空间（第57–59页）★三年级起为棱柱体/正多边形/对称轴
**目标**：解答相关应用题／通过棱柱体与非棱柱体图形珍视鉴赏数学之美／推理联系表示沟通工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 7.1 棱柱体 | 认识正方/长方/三角棱柱体；依表面底面顶点边标示特征（正方体即正方棱柱体，长方体即长方棱柱体） |
| 7.2 棱柱体和非棱柱体 | 依侧面底面顶点边比较两者（用模型） |
| 7.3 正多边形 | 确认正五/六/七/八边形；以正多边形设计图案 |
| 7.4 对称轴 | 确认并画出对称轴 |
| 7.5 解决问题 | 棱柱体与对称轴相关应用题 |

表现标准 1–6：讲述棱柱体正多边形对称轴 → 解说特征 → 比较棱柱非棱柱/画对称轴/设计图案 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 8.0 联系与代数 — 坐标（第60–62页）★三年级新增独立单元
**目标**：解答坐标相关应用题／珍视鉴赏数学之美／推理联系表示沟通工艺解决情境。

| 内容标准 | 学习标准要点 |
|---|---|
| 8.1 第一象限的坐标 | 依参考点用适当词汇（向右/向上/向东/向北）确认物体位置；依横纵轴位置说出物体名称；确定物体在横纵轴位置 |
| 8.2 解决问题 | 坐标相关日常应用题 |

表现标准 1–6：讲述位置词汇 → 依轴说出物体名称 → 确定物体位置 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 9.0 统计与概率 — 数据处理（第63–65页）★三年级新增饼分图
**目标**：掌握从饼分图获取资料的技能／解答相关应用题／作决策提想法解说日常情境／推理联系表示沟通工艺理解应用数据处理。

| 内容标准 | 学习标准要点 |
|---|---|
| 9.1 收集、分类和整理数据 | 依日常情境收集分类整理数据（用各种方式整理） |
| 9.2 饼分图 | 解读获取饼分图资料（简易词汇说明标题提示） |
| 9.3 象形统计图、条形统计图和饼分图之间的关系 | 联系三种图表所表示的资料，确认关系和表示适合性 |
| 9.4 解决问题 | 数据处理相关应用题 |

表现标准 1–6：读取三类图表资料 → 说明获取资料 → 确定答案合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

## 各单元表现标准共通结构（备忘）
与一/二年级一致的六级进阶逻辑：
1. 讲述/读出基本内容
2. 解说/确定/展示（初步操作）
3. 完成算式/比较/判断合理性（含验证意识）
4. 解答日常生活常规问题（单一策略）
5. 运用各种策略解答常规问题
6. 以创意创新方式解答**非常规**问题
