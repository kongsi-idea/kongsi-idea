## 5 个语文技能模组摘要（三年级）

### 1.0 听说技能
| 内容标准 | 三年级学习标准要点 |
|---|---|
| 1.1 进行口语交际 | 1.1.1 应用礼貌语言与人沟通交流，话语适当态度大方有礼；1.1.2 针对不明白的事情提出问题（教材：邀约/接待/拒绝/祝贺/赞美/慰问/鼓励他人） |
| 1.2 聆听口语和书面语 | 1.2.1 **耐心**聆听说话，边听边记边想（较二年级"安静"聆听提升为"耐心"）；1.2.2 听读理解教材（集会庆典讲话、成语故事等） |
| 1.3 进行口头表达 | 1.3.1 讲述事情经过，清楚交代时间地点人物情节，话语流畅态度大方；1.3.2 说明所进行的活动，要求说明清楚层次分明（新增"说明活动步骤/解决方法"） |

### 2.0 阅读技能
| 内容标准 | 三年级学习标准要点 |
|---|---|
| 2.1 阅读与理解教材 | 2.1.1 **借助字典**认识汉字，掌握词语，理解句段篇内容（新增字典工具使用）；2.1.2 阅读教材培养语感，体验情感，领会教育意义（教材：寓言/童话/神话/民间故事/记叙文） |
| 2.2 朗读教材，感悟其内容 | 2.2.1 语音正确字句完整，**能有感情地朗读**（较二年级"尝试"提升为"能"） |

### 3.0 书写技能
| 内容标准 | 三年级学习标准要点 |
|---|---|
| 3.1 应用铅笔写字 | 3.1.1 田字格上书写正楷，感受汉字形体美 |
| 3.2 培养书面表达能力 | 3.2.1 练习写话，能写自己想说的话，语句通顺句与句之间有联系；3.2.2 **习写便条和日记**（较二年级新增文体） |

### 4.0 趣味语文
| 内容标准 | 三年级学习标准要点 |
|---|---|
| 4.1 进行各类语文游戏 | 4.1.1 以有趣形式积累扩展词汇，操练语音 |
| 4.2 背诵古诗 | 4.2.1 背诵古诗十首 |
| 4.3 诵读和演绎教材 | 4.3.1 语音正确、语调恰当、生动自然有感情 |
| 4.4 分享阅读心得 | 4.4.1 针对所阅读材料，找出话题与人分享 |
| **4.5 习写毛笔字**（三年级新增） | 4.5.1 使用毛笔习写基本笔画和描红名家楷书字帖，坐姿执笔运笔笔画笔顺正确（教材：颜/柳/欧/赵楷书名家） |

> 备注：趣味语文不另设评价标准。

### 5.0 语文基础知识
| 内容标准 | 三年级学习标准要点 |
|---|---|
| 5.1 掌握汉字基本知识 | 5.1.1 汉字演变基本知识 |
| 5.2 学会汉语拼音 | 5.2.1 正确读出**"上声""一""不"的变调**（新增声调变化知识） |
| 5.3 认识各类词语 | 5.3.1 认识**多音多义字、成语**（较二年级"量词/近似字/多音字"更进阶） |
| 5.4 认识不同类型的句子 | 5.4.1 **了解关联词语的功能**，正确解读句子并应用 |
| 5.5 认识各种标点符号 | 5.5.1 **括号、书名号、间隔号**的使用（较二年级顿号冒号引号更进阶） |

> 备注：语文基础知识不另设评价标准；「5.6 认识修辞手法」从四年级起才新增。

## 与低年级（一、二年级）对照的年级递进重点（备忘）
- 聆听态度从"安静"（一二年级）→"耐心"（三年级起）
- 阅读首次引入"借助字典"工具使用
- 书写文体从写话扩展到"便条、日记"
- 三年级是毛笔字（4.5）与成语/多音多义字（5.3）首次出现的分水岭，标志「低年段→中年段」过渡
