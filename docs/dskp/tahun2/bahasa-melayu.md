## 总论重点

**课程宗旨**：与一年级一致——让学生具备良好语文能力，能沟通以满足自身需求、获取知识技能信息价值与想法，并建立日常生活中的社交关系。

**总体目标**：与一年级8项总体目标基本一致（回应指示口信提问、讲故事讨论发表意见、朗读理解显隐信息、广泛阅读丰富词汇、记录书写听写、创作编辑作品、欣赏文学语言之美、正确运用语文系统）。

**二年级17项具体目标**（较一年级明显进阶，节录要点）：聆听理解并说出短语／单句／复句，能对聚合式与发散式问题、祈使句、口信与请求作出准确解读；以批判创意想法得体地依语境说明显性与隐性信息；朗读词语／句子／段落／文章；阅读理解并辨识词汇、显隐信息，并说出童谣/故事/班顿/文章中的价值观；演绎童谣故事班顿及非文学篇章；抄写词语句子段落文章；造句写理解性答案（聚合/发散式）；整理记录有意义信息；听写词语短语句子；以半可控/引导方式创作记叙非记叙文，并从拼写标点用词角度编辑修订；讲述动物故事／幽默故事并运用适当成语与明喻；朗诵二/四行劝勉班顿（Pantun Nasihat）并辨识其"引子与主旨、押韵与停顿、写作格式"等特征，能半可控创作并展示；以正确节奏演唱儿歌与民谣并配合歌词做动作展示；依语境辨识普通名词/专有名词/代名词/量词；辨识主动及物动词/被动动词/性状颜色形状时态形容词；辨识连接词/介词/方位词/疑问词/祈使词/感叹词；辨识词根/单纯词/前缀衍生词/复合词/重叠词；依语境运用句型与句式。

**课程架构与焦点**：与一年级相同六大支柱框架；同属 Tahap I（一至三年级）基础读写听说全面掌握阶段。

**21世纪学生素质、KBAT**：与一年级相同（善于沟通、思考者、团队精神、坚毅、求知欲强、爱心/关怀、爱国、有原则、掌握信息；KBAT涵盖应用/分析/评价/创造）。

**教学策略**：与一年级相同的5P概念、补救与丰富化教学、掌握学习（80%掌握门槛）、模组教学法、探究式/合作式/情境式/主题式教学等；主题清单新增第12项「诚信 Integriti」（原一年级11项主题基础上扩充，强调诚实与高尚品德操守、言行与道德/法律原则一致、个人利益与公共利益一致）。

**跨课程元素 EMK（本版扩充为10项）**：语言、环境永续、良好价值观、科学与工艺、爱国精神、创意与革新、企业家精神、资讯与通讯工艺（TMK）、**全球永续**（新增）、**理财教育**（新增，含直接融入如单利复利计算的钱币课题，及渗透式融入其他课题）。
> 备注：相较一年级（2015/2016版）EMK仅列8项，二年级（2016版）已扩充至10项，是两份文件间最明显的课程更新差异。

**校内评估 Pentaksiran Sekolah（PS）**：定义、原则（全面/持续/灵活/依据课程标准）、形成性+总结性实施方式与「标准参照评估」精神与一年级完全一致。语文能力总体1–6级「掌握程度」诠释表（Jadual 3）：1非常有限 → 2有限 → 3满意 → 4良好 → 5非常好 → 6卓越（能成为其他学生的典范）——与一年级共用同一套诠释语言。

## 5 个语文技能模组摘要

### 1.0 聆听与说话技能 Kemahiran Mendengar dan Bertutur（第29页）
**较一年级进阶**：从字母/字词层级提升到短语／单句／复句层级，并新增「发散式问题的解读回应」。

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 聆听并作出回应 | 聆听、辨识、理解并准确说出短语／单句／复句；聆听理解并回应问句／祈使句／口信／请求 |
| 1.2 为各种目的说话以传达信息与想法 | 依语境得体地说明事项；以批判创意想法说明显性与隐性信息 |

**表现标准 1–6**：对各类问句/祈使句/口信/请求的回应，以及以批判创意方式传达显隐信息，从「非常有限」逐级进阶至「非常详尽、一致，成为示范」。

### 2.0 阅读技能 Kemahiran Membaca（第31页）
**较一年级进阶**：阅读材料单位从音节/词语/句子扩大到词语／句子／段落／篇章，并新增「从文学与非文学材料中辨识说出价值观」的学习标准。

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 基础阅读与理解 | 以正确发音语调朗读词语／句子／段落／篇章；阅读理解词语／句子／段落／篇章 |
| 2.2 阅读理解并推敲图文与非图文材料 | 阅读理解辨识词汇／显性信息／隐性信息 |
| 2.3 阅读并欣赏文学与非文学作品 | 从文学与非文学材料（儿歌、故事、班顿、篇章）中阅读辨识并说出其价值观 |
| 2.3.2 演绎作品 | 以正确发音语调朗读并演绎儿歌／故事／班顿／非文学篇章 |

**表现标准 1–6**：阅读理解材料内容并辨识文学/非文学作品中的价值观、演绎作品，从「非常有限」逐级进阶至「非常详尽、一致，成为示范」。

### 3.0 书写技能 Kemahiran Menulis（第34页）
**较一年级进阶**：书写单位扩大到词语／句子／段落／篇章，写作方式从「可控式」进阶为「半可控式／引导式」，编辑修订新增「用词」维度。

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 基础书写 | 机械式书写：词语／句子／段落／篇章 |
| 3.2 书写有意义的词语、短语、句子 | 造句并书写词语／短语／句子／段落；写聚合式／发散式理解性答案；整理记录有意义的信息；听写词语／短语／句子 |
| 3.3 完成写作作品 | 以半可控方式／引导方式创作记叙文与非记叙文；从拼写、标点、**用词**角度编辑修订作品 |

**表现标准 1–6**：机械式书写、造句、写理解性答案、记录信息、听写、创作作品、编辑修订，从「非常有限」逐级进阶至「非常详尽、一致，成为示范」（六年级表述略去"记叙非记叙"字样，聚焦写作与编辑整体表现）。

### 4.0 语文之美 Aspek Seni Bahasa（第37页）
**较一年级进阶**：讲故事题材扩充为「动物故事／幽默故事」并须运用成语与明喻；班顿从"一般班顿"进阶为「劝勉班顿」并须辨识其结构特征；演唱曲目新增「民谣」并须配合歌词做动作展示。

| 内容标准 | 学习标准要点 |
|---|---|
| 4.1 在文学作品中运用语言之美与得体元素 | 讲述并演绎含成语与明喻的对话（动物故事、幽默故事） |
| 4.2 领会文学作品中语言之美与得体 | 朗诵并辨识劝勉班顿特征（引子与主旨、押韵与停顿、写作格式）；以正确发音语调演唱儿歌／民谣旋律并配合歌词做动作 |
| 4.3 创作融入语言之美与得体的文学作品并创意展示 | 以半可控方式创作展示二／四行班顿；演绎动物／幽默故事；演绎儿歌／民谣 |

> 备注：本模组的聆听说话/阅读/书写技能评估可并入其他三大技能一并实施，教学仍以模组化方式进行（与一年级相同）。

### 5.0 语法 Aspek Tatabahasa（第38页）
**较一年级进阶**：词类新增「被动动词」「时态形容词」「疑问词/祈使词/感叹词」；构词法新增「词根、单纯词」；句子层面新增「句型（pola ayat）」「祈使句」学习标准。

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 理解并依语境运用词类 | 普通名词／专有名词／代名词／量词；主动及物动词／被动动词；性状／颜色／形状／**时态**形容词；连接词／介词／方位词／**疑问词／祈使词／感叹词** |
| 5.2 理解并依语境运用构词法 | **词根、单纯词**；前缀衍生词；复合词；重叠词 |
| 5.3 理解并依语境造句 | **句型**；陈述句／带疑问词疑问句／**祈使句**；基本句／单句／复句 |

> 备注：本模组评估同样可并入其他三大技能一并实施，教学仍以模组化方式进行。

## 表现标准共通结构（备忘）
与一年级完全一致的「语文能力总体掌握程度」6级诠释（Jadual 3），可直接作为分层习题/教案难度设计骨架：
1. 表现「非常有限」，需大量指导、示范与练习
2. 表现「有限」，需少量指导与练习
3. 表现「满意」，能表达想法并掌握基础思维技能，无需指导
4. 表现「良好」，能有效运用语文知识、批判思维，具最低限度自主学习
5. 表现「非常好」，能清晰详尽表达、有效沟通、掌握较复杂语文知识与批判创意思维、能自主学习
6. 表现「卓越」，清晰详尽有条理表达、掌握批判创意革新思维、充满自信有效沟通、完全自主学习，并成为其他学生的示范楷模

**二年级 vs 一年级的核心差异速查**：语言单位从「字母/音节/词语」提升到「词语/句子/段落/篇章」；写作方式从「可控式」进阶到「半可控/引导式」；EMK从8项扩充到10项（新增全球永续、理财教育）；主题清单新增「诚信」；语法内容显著扩充（新增被动语态、时态形容词、疑问/祈使/感叹词、词根单纯词、句型、祈使句）。备课投稿新工具构想时，若涉及跨年级难度分级设计，可直接对照本节差异表。
