## 5 个语文技能模组摘要（二年级）

### 1.0 听说技能
| 内容标准 | 二年级学习标准要点 |
|---|---|
| 1.1 进行口语交际 | 1.1.1 应用礼貌语言，学会与人沟通交流，话语适当态度有礼；1.1.2 针对不明白的事情提出问题，正确应用疑问代词 |
| 1.2 聆听口语和书面语 | 1.2.1 安静聆听说话，边听边记边想，听懂内容；1.2.2 听读与理解教材，理解主要内容 |
| 1.3 进行口头表达 | 1.3.1 讲述事情经过，能交代时间地点人物情节；1.3.2 说明人和物，能描述外貌轮廓和重要细节及较突出特点（较一年级增加"重要细节"要求） |

### 2.0 阅读技能
| 内容标准 | 二年级学习标准要点 |
|---|---|
| 2.1 阅读与理解教材 | 2.1.1 认识汉字、掌握词语、理解句段篇内容；2.1.2 阅读教材培养语感，体验情感，体会阅读乐趣 |
| 2.2 朗读教材，感悟其内容 | 2.2.1 语音正确字句完整语速语调适当，**开始尝试有感情地朗读**（较一年级新增） |

### 3.0 书写技能
| 内容标准 | 二年级学习标准要点 |
|---|---|
| 3.1 应用铅笔写字 | 3.1.1 田字格上书写正楷，感受汉字形体美，执笔运笔坐姿笔画笔顺正确 |
| 3.2 培养书面表达能力 | 3.2.1 练习写话，尝试书面表达，不拘形式写自己想说的话，**对写话产生信心和兴趣**（较一年级新增"信心"要求） |

### 4.0 趣味语文
| 内容标准 | 二年级学习标准要点 |
|---|---|
| 4.1 进行各类语文游戏 | 4.1.1 以有趣形式积累扩展词汇，操练语音（与一年级相同） |
| 4.2 背诵古诗 | 4.2.1 背诵古诗十首 |
| 4.3 诵读和演绎教材 | 4.3.1 语音正确、语调恰当、生动自然有感情 |
| 4.4 分享阅读心得 | 4.4.1 针对所阅读材料，与他人分享故事情节 |

> 备注：趣味语文不另设评价标准；「4.5 习写毛笔字」从三年级起才新增。

### 5.0 语文基础知识
| 内容标准 | 二年级学习标准要点 |
|---|---|
| 5.1 掌握汉字基本知识 | 5.1.1 汉字演变基本知识；5.1.2 笔画/部首/偏旁和结构、笔顺规则 |
| 5.2 学会汉语拼音 | 5.2.1 正确认读音节，念准字音 |
| 5.3 认识各类词语 | 5.3.1 认识量词、近似字、多音字，辨析理解词义 |
| 5.4 认识不同类型的句子 | 5.4.1 陈述/疑问/祈使/感叹句功能，**新增常用关联词语**认识（较一年级新增） |
| 5.5 认识各种标点符号 | 5.5.1 **顿号、冒号、引号**的使用（较一年级句号问号叹号逗号更进阶） |

> 备注：语文基础知识不另设评价标准；「5.6 认识修辞手法」从四年级起才新增。

## 与一年级对照的年级递进重点（备忘）
- 口语交际、书面表达强调从"敢于说/写"提升到"话语适当态度有礼／有信心和兴趣"
- 标点符号从句号问号叹号逗号（一年级）→ 顿号冒号引号（二年级），难度递增
- 句子知识新增"关联词语"的认识与运用
- 朗读要求首次出现"尝试有感情地朗读"
