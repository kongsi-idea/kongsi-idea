## 总论重点

**数学教育宗旨**：塑造具数学思考力的学生——理解数的概念、基本计算技能、简单数学想法，能在日常生活中有效且负责任地应用数学解决问题和作出决策，持正面态度与价值观。

**十项课程目标**：培养数学思考力／理解应用概念技能／扩展四则运算技能／联系数学与生活／正确沟通数学想法／解决问题／建构高层次思维／运用多元表示／珍视数学之美／善用数学器材（含ICT）。

**五项学习领域**：数与运算、测量与几何、联系与代数、统计与概率、离散数学（小学阶段不涉及）。

**五项数学过程**（教学须贯穿）：解决问题、推理、沟通、联系、表示。
- 解决问题步骤：理解诠释问题 → 拟定策略 → 进行策略 → 验算
- 解题策略举例：画图表、找规律、列表、代数法、由易入手、逻辑推理、尝试法、模拟情境、逆运算、类推法

**数学技能**：分析技能、解决问题技能、研究技能、沟通技能、工艺使用技能。

**态度与价值观**：数学价值观（数学知识本身特征）＋态度与普世价值观（良好习惯与道德价值）；融入宗教信仰、兴趣、感激、信心、效率、毅力，以及历史/爱国元素。

**21世纪学生素质**（表2）：坚毅、善于沟通、思考者、具团队精神、具求知欲、有原则、掌握信息、有爱心、爱国。

**高层次思维技能 KBAT**（表3）：应用、分析、评价、创造。可通过思维图表、思维导图、高层次提问技巧激发。

**教学策略**：全握学习、情境学习、专题课业导向学习、问题导向学习、模拟学习（角色扮演/游戏/模型）、探究学习、模组式学习、STEM教学法。

**跨课程元素（10项）**：语言、环境永续、道德价值观、科学与工艺、爱国精神、创造力和创新、企业家精神、通讯与资讯工艺、全球永续、**理财教育**（钱币单元是理财教育直接融入的代表课题，如单利复利计算）。

**校内评估**：
- 分内容、技能与过程、态度与价值观三方面，形成性＋总结性评估
- 通用数学级别诠释（表4）共 6 级：1知道基本知识 → 2知道理解基本知识 → 3能作基本运算/换算 → 4有步骤解答常规问题 → 5各种策略解答常规问题 → 6创意创新解答非常规问题
- 数学技能与过程评估（表5）：解决问题/推理/沟通/联系/表示，各分 1–6 级，逐级要求从「他人引导」进阶到「自行创意解答非常规问题」
- 整体报告（表7）：综合内容+技能过程+态度价值观，1–6级

## 8 个学习单元摘要

### 1.0 数与运算 — 1000 以内的整数（第31–34页）
**目标**：认识理解应用1000以内整数／解答相关应用题／在学习中运用推理联系表示沟通与工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 数值 | 读/说/配对数字与文字；展示数量、比较大小、顺逆序排列（用实物、图片、数轴、1:4珠算盘） |
| 1.2 写出数目 | 以数字和文字写出 |
| 1.3 数列 | 数数、完成数列（一个一个至十个十个、一百个一百个，顺逆序） |
| 1.4 数位 | 讲述数位与数值、依数位数值分析数目 |
| 1.5 估算 | 合理估算物体数量（大约/少于/多于） |
| 1.6 近似值 | 找出至百位的近似值 |
| 1.7 有规律的数列 | 确认规律、完成简易规律数列 |
| 1.8 解决问题 | 1000以内整数应用题 |

表现标准 1–6：讲述数目 → 确定排序 → 估算/近似值/数列 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 2.0 数与运算 — 基本运算（第35–38页）
**目标**：理解应用四则运算的概念技能程序／运用知识技能解答问题／正确数学语言／推理联系表示沟通工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 加法（1000以内） | 两数加法、三数连加法 |
| 2.2 减法（1000以内） | 两数减法、三数连减法 |
| 2.3 乘法（1000以内） | 基本乘法（一位数×一位数）、一位数×10；乘法即相同数连加；联系交换律 a×b=b×a |
| 2.4 除法（1000以内） | 基本除法（含/不含余数）、二位数÷10；平均分配法/等量分组法/连减法/乘法逆运算 |
| 2.5 解决问题 | 编写涉及四则运算的故事；解答日常应用题（审题→拟策略→进行→验算） |

表现标准 1–6：读算式 → 确定讲述算式 → 完成算式判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 3.0 数与运算 — 分数与小数（第39–42页）
**目标**：联系分数小数与日常生活／用表示推理沟通探究理解概念。

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 真分数 | 分子1、分母至10的真分数确认说出；分子至9分母至10；图表表示、写出、比较两真分数值（实物/图片/折纸） |
| 3.2 小数 | 分母10的真分数化小数；说出展示0.1–0.9；图表表示、写出、比较两小数值（数轴） |
| 3.3 分数与小数 | 比较分数与小数的值 |
| 3.4 解决问题 | 分数小数相关应用题 |

表现标准 1–6：讲述真分数小数 → 写出/图表表示 → 比较值 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 4.0 数与运算 — 钱币（第43–46页）
**目标**：把钱币与日常生活联系／应用理财知识／对钱财使用进行思考推理探究／钱财沟通联系解决问题／**培养企业精神**。

| 内容标准 | 学习标准要点 | 备注 |
|---|---|---|
| 4.1 纸币和硬币 | 确认RM100以内马币、确定RM100以内币值 | 日常生活用钱；1:4珠算盘表示币值；以硬币纸币组成指定币值 |
| 4.2 钱币加法 | RM100以内两个币值加法、三个币值加法 | |
| 4.3 钱币减法 | RM100以内两个币值减法、三个币值连减法 | |
| 4.4 钱币乘法 | 积在RM100以内的乘法 | 币值×一位数、×10 |
| 4.5 钱币除法 | RM100以内的除法 | 币值÷一位数、÷10 |
| 4.6 储蓄与投资 | 以有效理财作为储蓄消费基础 | 情境解说RM1000以内理财 |
| 4.7 解决问题 | 钱币相关日常应用题 | |

表现标准 1–6：讲述RM100以内币值 → 确定币值 → 确定算式答案合理性/解说有效理财 → 常规问题 → 多策略常规问题 → 创意非常规问题。

> 备课提示：这是唯一明确点名「企业家精神」为单元目标、且是理财教育跨课程元素直接融入课题的单元；教案可结合「组成指定币值」「找零钱」「储蓄情境」等实作活动，呼应马来西亚令吉纸币/硬币的实物辨识。

### 5.0 测量与几何 — 时间与时刻（第47–49页）
**目标**：理解模拟钟数码钟／沟通建构描述时间情境／思考推理联系表示工艺解决问题／有效利用时间。

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 时刻 | 确认钟面分钟刻度；讲述展示时分时刻；文字数字互换；以时分记录时刻（先教「时」和五分钟倍数，再教一刻/半/三刻） |
| 5.2 时间单位关系 | 天与时、时与分的关系 |
| 5.3 解决问题 | 时间相关应用题 |

表现标准 1–6：讲述刻度时刻 → 文字数字互换/单位关系 → 记录时刻判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 6.0 测量与几何 — 度量衡（第50–53页）
**目标**：用实物建构度量衡概念并应用／对度量衡思考推理沟通探究／联系表示解决问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 6.1 长度 | 认识米/厘米单位（观察尺/卷尺）；测量记录距离物体长度；依长度画直线；估算长度并与实际比较 |
| 6.2 质量 | 认识公斤/克单位（观察秤）；称重记录；估算质量并比较 |
| 6.3 液体的体积 | 认识升/毫升单位（观察量筒）；测量标记记录；估算并比较 |
| 6.4 解决问题 | 度量衡相关应用题 |

表现标准 1–6：认识单位 → 测量 → 估算比较判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 7.0 测量与几何 — 空间（第54–56页）
**目标**：理解应用空间概念与技能／推理沟通联系表示工艺解决问题／通过立体平面图形鉴赏数学之美。

| 内容标准 | 学习标准要点 |
|---|---|
| 7.1 立体图形 | 依特征确认立体（正方体/长方体/正方棱锥体/圆柱体/圆锥体）；确认基本图形；确认展开图 |
| 7.2 平面图形 | 依特征确认平面图形（正方形/长方形/三角形/圆）；画出基本平面图形 |
| 7.3 解决问题 | 空间相关应用题 |

表现标准 1–6：讲述立体平面图形 → 确认基本图形 → 依展开图确认立体/画图形/判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 8.0 统计与概率 — 数据处理（第57–59页）
**目标**：掌握获取条形统计图资料的技能／沟通思考推理决策表达想法／用工艺建构数据处理概念应用数学知识。

| 内容标准 | 学习标准要点 |
|---|---|
| 8.1 收集分类整理数据 | 依日常情境收集数据；用各种方法整理 |
| 8.2 条形统计图 | 解读获取条形统计图资料（纵横轴一刻度=一单位） |
| 8.3 解决问题 | 数据处理相关应用题（简易词汇解说标题/提示/纵轴/横轴） |

表现标准 1–6：解读资料 → 收集数据 → 判断资料合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

## 各单元表现标准共通结构（备忘）
几乎所有单元的 6 级表现标准都遵循同一套进阶逻辑，方便快速套用出题难度分级：
1. 讲述/读出基本内容
2. 确定/写出/展示（初步操作）
3. 估算/比较/判断合理性（含验证意识）
4. 解答日常生活常规问题（单一策略）
5. 运用各种策略解答常规问题
6. 以创意创新方式解答**非常规**问题

这套「1–6级」结构可直接作为分层习题/教案难度设计的骨架。
