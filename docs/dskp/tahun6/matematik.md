## 8 个学习单元摘要（六年级为小学收官册：钱币→钱财管理并首次系统教保险/回教保险；时间单位新增时区；数据处理与可能性合并为单元8）

### 1.0 数与运算 — 整数与基本运算（第29–32页）★首次引入合数、以百万为单位的分数小数
**目标**：认识理解应用10000000以内整数、质数和合数／应用知识技能解答问题／正确数学语言／推理联系表示沟通工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 10000000以内的整数 | 读说写任何数目；表示数目并确定有规律数列；读说写以百万为单位的分数（分母2/4/5/8/10，涉及真分数带分数）；以百万为单位的小数（至三位小数）；小数分数与整数互换（笔记：可介绍十亿和一兆数位） |
| 1.2 基本运算和混合运算 | 完成涉及整数、百万分数、百万小数（含未知数）的基本运算及有括号无括号混合运算（笔记：强调括号运算规则） |
| 1.3 质数和合数 | 将100以内数目归类为质数和合数（笔记：合数可被1、本身和其他数整除；0和1既非质数也非合数） |
| 1.4 解决问题 | 整数、质数合数、百万分数小数（含未知数）相关应用题 |

表现标准 1–6：讲述数目/用工具表示 → 解说算式步骤/换算分数小数整数 → 归类质数合数/用计算器确认数列/完成算式判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 2.0 数与运算 — 分数、小数与百分比（第33–36页）★首次出现分数除法、小数乘小数、超过100%百分比加减
**目标**：联系分数小数百分比与日常生活／应用知识技能解答问题／推理联系表示探究沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 分数 | 两数除法（涉及真分数整数带分数，分母10以内） |
| 2.2 小数 | 小数与小数乘法（答案至三位小数）；小数与小数除法（答案至三位小数） |
| 2.3 百分比 | 小数化大于100%百分比或反之；百分比加减法算式；从有小数数量确定大于100%百分比或反之（笔记：百分比带分数在100%以内和大于100%） |
| 2.4 混合运算 | 整数、小数、分数有括号无括号混合运算（涉及任两个不同基本运算） |
| 2.5 解决问题 | 整数分数小数百分比相关应用题 |

表现标准 1–6：读算式 → 小数化百分比/解说算式步骤 → 完成算式判断合理性/确定大于100%百分比 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 3.0 数与运算 — 钱币（第37–39页）★升级为「钱财管理」，首次系统引入保险与回教保险
**目标**：日常生活应用理财知识／探究钱财使用以利未来生活／推理联系表示沟通工艺解答问题／**展现并实践企业家精神**。

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 钱财管理 | 认识成本/售价/盈利/亏损/折扣/回扣/礼卷/账单/收据/发票/资产/负债/利息/股息/服务税；确定以上各项数值（笔记：教资产时可介绍贬值；联系资产与保险） |
| 3.2 保险与回教保险 | 认识保险与回教保险；说明其目的和保障重要性（笔记：功能为保障资产与缴纳者） |
| 3.3 解决问题 | 上述理财概念及钱财管理与风险相关应用题 |

表现标准 1–6：认识各理财术语 → 解说各理财术语/讲述保险回教保险重要性 → 确定盈利亏损折扣回扣利息股息服务税数值判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

> 备课提示：六年级钱币单元完成从「钱币运算」到「财商教育」的最终跃迁——首次出现保险/回教保险、服务税、资产负债等真实理财术语，教案可结合毕业前「理财规划」情境任务，呼应企业家精神跨课程元素收官。

### 4.0 测量与几何 — 时间与时刻（第41–43页）★首次引入时区概念
**目标**：有效管理时间／清楚传达时间与时刻情境／应用知识技能解答问题／推理联系表示沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 4.1 时区 | 认识时区；确定两个不同时区城市之间的时差（笔记：有些国家有超过一个时区，如澳洲印尼） |
| 4.2 解决问题 | 时区相关应用题（用计算策略包括数轴） |

表现标准 1–6：认识时区 → 解说时差 → 确定时差 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 5.0 测量与几何 — 度量衡（第45–47页）★六年级度量衡单元仅剩「解决问题」一项内容标准，聚焦长度/质量/体积三者跨单位综合应用
**目标**：应用知识技能解答度量衡问题／推理联系表示探究沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 解决问题 | 解答涉及长度与质量、长度与液体体积、质量与液体体积之间关系的应用题 |

表现标准 1–6：讲述度量衡数量 → 解说两数量关系 → 依应用题写出算式判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 6.0 测量与几何 — 空间（第49–51页）★首次引入画正多边形、画角度、认识圆（圆心/半径/直径）
**目标**：应用知识技能解答空间问题／通过几何图形珍视鉴赏数学之美／推理联系表示沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 6.1 角度 | 在方格图/等边三角形格子图/软件中画出至八边正多边形并测量内角；依所给角度值画角度（笔记：用量角器和尺，角度值至180°；活动建议可用MS Word/Excel/几何画板软件） |
| 6.2 圆 | 认识圆心、直径、半径；依半径值画圆并标示圆心半径直径（笔记：一个完整圆是360°，称周角） |
| 6.3 解决问题 | 空间相关应用题 |

表现标准 1–6：认识标示圆心直径半径 → 说明圆心直径半径和内角 → 画正多边形测内角/画角度/画圆 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 7.0 联系与代数 — 坐标、比与比例（第53–55页）★首次引入比例尺
**目标**：应用知识技能解答坐标比比例问题／推理联系表示沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 7.1 第一象限的坐标 | 依比例尺确定两位置间横向直向距离（笔记：以坐标表示位置；比例尺示例如1厘米代表1公里、1:100000；强调正确读比例尺读数） |
| 7.2 比 | 以最简化形式表示两数量之比（笔记：比只涉及整数） |
| 7.3 比例 | 依所给比确定按比例的数量（可确定一个或两个数量） |
| 7.4 解决问题 | 坐标比比例相关应用题 |

表现标准 1–6：读比例尺/讲述比 → 解说表示比/依比确定数量/确定横直向距离步骤 → 以最简形式表示比/依比确定数量/依比例尺确定距离 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 8.0 统计与概率 — 数据处理与可能性（第57–59页）★首次将「可能性」并入本单元、首次教依角度值完成饼分图
**目标**：掌握从饼分图获取资料的技能／应用知识技能解答数据处理和可能性问题／作决策提想法解说日常情境／推理联系表示沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 8.1 饼分图 | 依45°/90°/180°角度值和所给数量完成饼分图，并诠释数据 |
| 8.2 可能性 | 讲述某事件可能/不可能发生并给理由；讲述事件发生可能性程度（不可能/可能性小/可能性相同/可能性大/肯定）并给理由 |
| 8.3 解决问题 | 数据处理与可能性相关应用题 |

表现标准 1–6：讲述事件可能/不可能发生 → 讲述事件发生可能性程度并给理由 → 依角度值数量完成饼分图并诠释 → 常规问题 → 多策略常规问题 → 创意非常规问题。

## 各单元表现标准共通结构（备忘）
与一至五年级一致的六级进阶逻辑，六年级收官册维持不变：
1. 讲述/认识基本内容
2. 解说步骤/含义（初步操作）
3. 完成算式/画图/归类/判断合理性（含验证意识）
4. 解答日常生活常规问题（单一策略）
5. 运用各种策略解答常规问题
6. 以创意创新方式解答**非常规**问题
