## 总论重点
与三至五年级相同的课程框架（详见 `tahun1/sains.md`）。**六年级是小学科学的总结年**，课题数量最多（13个），涵盖繁殖生理（人类繁殖/神经系统）、生态保育、力学（力/摩擦力/气压/速度）、食品科技、天文（日食月食/星系）与结构工程（平稳性坚固性），综合应用与创新沟通的层级要求也最高。

## 13 个课题摘要（六年级）

### 生命科学
| 内容标准 | 六年级学习标准要点 |
|---|---|
| 2.1 人类的繁殖 | 讲述男女生殖器官功能；解释受精至婴儿出生过程；推论繁殖对人类的重要性 |
| 2.2 神经系统 | 确认神经系统种类（中枢/周围）；讲述中枢神经系统功能；预测周围神经系统失效的情况；推论照顾神经系统的方法 |
| 3.1 微生物的生命过程与其影响 | 解释举例微生物种类（真菌/原生动物/藻类/细菌/病毒）；讲述生命过程；实验确认影响生长的条件（温度/养分/酸度/水/空气）；讲述微生物对生活的影响 |
| 4.1 动物之间的相互关系 | 讲述相互关系种类（捕食/竞争/共生）；解释举例同种/不同种动物竞争因素；举例共生关系（互利共生/共栖/寄生） |
| 4.2 植物之间的相互关系 | 讲述植物竞争因素；举例植物共生关系种类 |
| 5.1 保护与复育以维持自然界平衡 | 说出保护复育定义；举例已绝种/濒临绝种动植物；讲述导致濒危的因素；举例保护复育方法；推论其重要性 |

### 物理科学
| 内容标准 | 六年级学习标准要点 |
|---|---|
| 6.1 力和力的效应 | 说出力的定义（推或拉）；解释举例力的效应（改变形状/方向/速度/使物体动或停） |
| 6.2 摩擦力 | 说出摩擦力定义；讲述效应；实验确定影响摩擦力因素；应用知识增减摩擦力解决问题 |
| 6.3 气压 | 讲述气压存在；联系气压与高度关系（山顶气压比山脚低）；举例解释生活中气压应用 |
| 7.1 速度 | 实验确定速度距离时间关系；说出速度单位（km/j、m/s、cm/s）；应用公式解决速度问题 |

### 材料科学
| 内容标准 | 六年级学习标准要点 |
|---|---|
| 8.1 食物的变质 | 解释举例变质食物特征；讲述食物变质由微生物造成 |
| 8.2 食物保存 | 讲述保存目的；联系保存法与影响微生物生长因素；专题课业应用各种保存法；总结食物可结合多种保存法 |
| 9.1 废物处理 | 依材料种类确认废物；分类可/不可生物降解废物；推论明智应用两类材料；讲述妥善处理废物（5R：减少/再使用/回收等） |

### 地球与宇宙
| 内容标准 | 六年级学习标准要点 |
|---|---|
| 10.1 月食和日食的自然现象 | 模拟月球地球太阳位置讲述月食日食现象；以光的特性联系月食日食；预测发生时地球上的情况（观察安全须知：避免肉眼直视日食） |
| 11.1 银河系 | 说出星系定义；讲述银河系；总结太阳系位于银河系内；模拟显示太阳系体积相对银河系的渺小 |

### 工艺
| 内容标准 | 六年级学习标准要点 |
|---|---|
| 12.1 物体和建筑的平稳性和坚固性 | 讲述定义；解释举例坚固平稳结构；实验确定影响平稳性因素（底部面积/高度/重心）与坚固性因素（材料种类/结构）；运用可回收材料创造模型 |
| 13.1 工艺的利与弊 | 说出工艺定义与重要性；讲述各领域工艺进展；举例工艺利弊；推论人类对工艺的需求 |

## 与前五年级对照的年级递进重点（备忘）
- 生命科学从"物种生存策略/食物链"（五年级）深化到"人类繁殖生理、神经系统、微生物学、生态保育"等更专业的科学概念
- 物理科学首次系统涉及"力学"（力/摩擦力/气压/速度公式计算），是小学阶段最接近中学物理的内容
- 六年级是唯一同时出现"日食月食＋银河系"完整天文单元、以及"结构工程（平稳性坚固性）"的年级
- 食物保存科技、废物处理（5R）等应用型/环保型课题集中在六年级收尾，呼应小学科学教育"回归生活应用"的总结定位
