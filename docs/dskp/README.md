## 已知的网站结构陷阱（供以后补建其他科目时参考）
- BPK 官网（bpk.moe.gov.my）没有统一搜索功能，年级分类页的 URL 代号与实际年级不一致（例如"四年级"文件夹的网址代号常年写成 `kssr-tahun-3-1`），必须实际打开页面核对文件标题，不能只看网址猜年级。
- 同一科目常有 SK（国小）与 SJK（华小）两个版本，标题/内容标准架构可能不同，下载前要核对文件标题里是否有「SJKC」或「SJK」字样。
- `jpnpp.moe.gov.my`（教育部槟城州教育局）是比主站更完整、结构更统一的官方镜像站，某些主站缺失或路径混乱的科目可以从这里找到。
