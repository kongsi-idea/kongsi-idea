## 总论重点

**课程目标（修完小学华文课程后，学生应能）**：①日常生活中有礼貌沟通、讨论中达成共识解决问题；②专注耐心听话获取信息、流畅叙事说理发表意见；③认识汉字约2500个，能以硬笔和毛笔书写；④掌握阅读技巧从各类媒体获取信息，正确流利有感情朗读；⑤具备自行阅读独立思考欣赏文字的能力；⑥应用各类应用文与人互通信息；⑦掌握书面表达能力，养成写作兴趣；⑧积极参与语文活动；⑨通过语文教学培养品德与爱国情操。

**六大领域框架**：交际、精神态度与道德价值、人文、科学与工艺、体健与美育、个人才能——华文课程依此框架编订。

**21世纪技能／高层次思维技能KBAT**：应用、分析、评价、创造，透过推理活动、探究性学习、问题解决融入教学。

**跨课程元素 EMK（本版列8项）**：语言、环保意识、道德价值、科学与工艺、爱国精神、创意和革新、企业家精神、通信和信息技术。

**内容标准／学习标准／表现标准关系**：内容标准以课程目标为依据，总括性列出各年级教学内容；学习标准具体说明该年级应达到的指标，逐年级递进——**内容标准（X.X级）在各年级文字基本相同，实际年级差异体现在学习标准（X.X.X级）的深浅**；表现标准把学习表现分为1–6级供校内评估参照。

**校内评估共通6级）**：1尚未掌握 → 2有待改进 → 3基本掌握 → 4满意 → 5良好 → 6优良。

## 5 个语文技能模组摘要（一年级）

### 1.0 听说技能
| 内容标准 | 一年级学习标准要点 |
|---|---|
| 1.1 进行口语交际 | 1.1.1 初步应用礼貌语言，学习与人沟通交流；1.1.2 针对不明白的事情提出问题，初步应用疑问代词，态度有礼（教材建议：请安/问候/道谢/道歉/告别/借光/请教/商借/请求） |
| 1.2 聆听口语和书面语 | 1.2.1 聆听通知与要求，具安静聆听意识，边听边记边想；1.2.2 听读与理解教材（故事/童诗/儿歌），理解主要内容 |
| 1.3 进行口头表达 | 1.3.1 讲述事情经过，能简单交代时间地点人物情节，敢于说话；1.3.2 说明人和物，能注意基本外貌特点 |

### 2.0 阅读技能
| 内容标准 | 一年级学习标准要点 |
|---|---|
| 2.1 阅读与理解教材 | 2.1.1 认识教材中汉字，掌握词语，理解句子段落篇章内容；2.1.2 阅读教材培养语感，初步体验情感，感受语言优美（教材：童诗/儿歌/儿童故事） |
| 2.2 朗读教材，感悟其内容 | 2.2.1 语音正确、字句完整、语速语调适当地朗读 |

### 3.0 书写技能
| 内容标准 | 一年级学习标准要点 |
|---|---|
| 3.1 应用铅笔写字 | 3.1.1 在田字格上书写基本笔画和正楷，执笔运笔正确，坐姿端正，笔画笔顺正确 |
| 3.2 培养书面表达能力 | 3.2.1 练习写话，初步尝试书面表达，不拘形式写自己想说的话，学习使用标点符号（教材建议：看图写话、读课文写话、听故事写话、感受生活写话） |

### 4.0 趣味语文
| 内容标准 | 一年级学习标准要点 |
|---|---|
| 4.1 进行各类语文游戏 | 4.1.1 以有趣形式积累扩展词汇，操练语音 |
| 4.2 背诵古诗 | 4.2.1 背诵古诗十首，初步理解诗歌内容 |
| 4.3 诵读和演绎教材 | 4.3.1 语音正确、语调恰当、生动自然有感情 |
| 4.4 分享阅读心得 | 4.4.1 针对所阅读材料，与他人分享故事情节 |

> 备注：趣味语文不另设评价标准，课堂评价依语文技能评价标准进行。「4.5 习写毛笔字」从三年级起才新增。

### 5.0 语文基础知识
| 内容标准 | 一年级学习标准要点 |
|---|---|
| 5.1 掌握汉字基本知识 | 5.1.1 掌握汉字演变基本知识；5.1.2 认识笔画/部首/偏旁和结构，掌握笔顺规则 |
| 5.2 学会汉语拼音 | 5.2.1 正确认读音节，说话朗读时念准字音 |
| 5.3 认识各类词语 | 5.3.1 认识量词和近似字、多音字，辨析理解词义 |
| 5.4 认识不同类型的句子 | 5.4.1 认识陈述、疑问、祈使、感叹等句子功能 |
| 5.5 认识各种标点符号 | 5.5.1 句号、问号、叹号、逗号的使用 |

> 备注：语文基础知识不另设评价标准；「5.6 认识修辞手法」从四年级起才新增。

## 各年级共通结构（备忘）
- **内容标准（X.X）跨年级基本不变**，仅「趣味语文」在三年级新增4.5习写毛笔字、「语文基础知识」在四年级新增5.6修辞手法；真正体现年级差异的是学习标准（X.X.X）的深度与广度。
- **表现标准6级（尚未掌握→有待改进→基本掌握→满意→良好→优良）**是各模组通用的评价语言，可直接作为分层习题/教案难度设计的骨架。
