## 总论重点

**数学教育宗旨**：塑造具数学思考力的学生——理解数学概念、基本计算能力、简单数学理念，在日常生活中有效负责任地应用数学解决问题和作决策，并具正确的态度和价值观，以面对21世纪科学工艺挑战。

**十项学习目标**：培养数学思考力／理解应用概念技能／扩展四则运算技能于各领域／联系数学与其他领域及生活／正确沟通数学想法与符号／应用知识技能解决问题／高层次思维探索推理／应用各种表示法／珍视鉴赏数学之美／有效应用数学器材（含ICT）。

**五项学习领域**：数与运算、测量与几何、联系与代数、统计与概率、离散数学（小学阶段不涉及）。

**五项数学过程**（教学须贯穿）：解决问题、推理、沟通、表示、联系。
- 解决问题步骤：理解诠释问题 → 拟定策略 → 进行策略 → 验证/反思
- 解题策略举例：画图表、确认规律、制作有系统图表、运用代数、模拟情境、逻辑推理、一个一个试、由易入手、逆运算、类推

**数学技能**：数学技能、分析技能、解决问题技能、研究技能、沟通技能、使用工艺技能。

**价值观**：数学教育价值观／数学价值观（合理、有目标、掌握能力、进展、坦率、隐藏misteri）／核心价值（普及价值）；融入信仰、兴趣、赏识、信心、效率、毅力，以及历史/爱国元素。

**21世纪学生素质**：坚毅、善于沟通、勤于思索、具团队精神、具求知欲、有原则、掌握信息、有爱心、爱国。

**高层次思维技能 KBAT**：应用、分析、评价、创造；通过思维图表、思维导图、高层次提问技巧激发。

**教学策略**：多元均衡策略、结构化提问、探究学习、专题课业、协作学习、全握学习、情境教学（konstruktivisme）、建构主义等。

**跨课程元素（8项，一年级文件列法）**：语言、爱护环境意识、道德价值、科学与工艺、爱国精神、创意和革新、企业家精神、通讯与资讯工艺。

**校内评估**：
- 三方面：数学课程内容评估、数学技能与学习过程评估、态度与道德价值观评估
- 通用级别诠释（表4/5）共 6 级：1知道基本知识／技能 → 2知道理解／诠释解说表示理解 → 3情境中应用技能 → 4有步骤有系统应用 → 5新情境正面态度有步骤系统应用 → 6新情境创意创新应用并可为楷模
- 数学知识整体级别诠释（表6）：1知道基本知识 → 2知道理解基本知识 → 3知道理解并能基本运算换算 → 4有步骤解答常规应用题 → 5各种策略解答常规应用题 → 6创意创新解答非常规应用题

## 8 个学习单元摘要

### 1.0 数与运算 — 100 以内的整数（第32–35页）
**目标**：认识明白应用100以内整数／推理联系表示沟通使用工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 以直观法说出数量 | 通过比较讲述数量（多/少、相等/不相等、多于/少于），成组物体、一对一配对、有规律讲述 |
| 1.2 数值 | 说出100以内数目（数数、说出、比较）；确定数值（展示、配对、比较、顺逆序排列） |
| 1.3 写出数目 | 以数字和文字写出；先一位数后0；11–19由「10和1」至「10和9」组成 |
| 1.4 数目的组合 | 讲述组成一位数的组合（如8由7和1、6和2等组成） |
| 1.5 数列 | 数数、完成数列（一个一个、两个两个、五个五个、十个十个、四个四个，顺逆序） |
| 1.6 数位 | 讲述任何数目的数位与数值（1:4珠算盘等） |
| 1.7 估算 | 合理估算物体数量（大约/少于/多于） |
| 1.8 近似值 | 找出整数的十位近似值 |
| 1.9 数列的规律 | 确认规律、完成简易规律数列 |
| 1.10 解决问题 | 100以内整数应用题 |

表现标准 1–6：讲述数目 → 确定数值排序 → 估算/近似值/数列 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 2.0 数与运算 — 基本运算（第36–39页）
**目标**：理解应用加减法概念程序／运用知识技能解决问题／推理联系表示沟通工艺／加减法应用正确数学术语。

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 加和减的概念 | 使用相关词汇；介绍「加」「减」「等于」符号；依情境写出算式 |
| 2.2 100以内的加法 | 基本加法；两数（100以内）加法 |
| 2.3 100以内的减法 | 基本减法；两数（100以内）减法 |
| 2.4 解决问题 | 编写涉及加减法的故事；解答日常应用题（审题→拟策略→进行→验算） |
| 2.5 连加法 | 两个两个/五个五个/十个十个/四个四个地加（连加相同数即乘法概念雏形） |
| 2.6 连减法 | 同上式连减（连减相同数即除法概念雏形） |

表现标准 1–6：讲述加减符号词汇 → 直觉讲述基本加减法 → 100以内两数加减法/连加连减/判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 3.0 数与运算 — 分数（第40–42页）
**目标**：以表示推理探究理解分数概念／联系分数与日常生活。

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 二等份和四等份的真分数概念 | 确认 1/2、1/4、2/4、3/4；用实物、折纸、图片解释 |
| 3.2 解决问题 | 分数相关日常应用题 |

表现标准 1–6：讲述分数 → 涂黑表示 → 用实物折纸建构 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 4.0 数与运算 — 钱币（第43–46页）
**目标**：钱币与日常生活联系／对钱财使用思考推理探究／钱财沟通联系解决问题／应用理财知识／**培养企业精神**。

| 内容标准 | 学习标准要点 |
|---|---|
| 4.1 纸币和硬币 | 确认马来西亚硬币纸币；表示币值（仙RM1以内、令吉RM10以内）；进行换算 |
| 4.2 经济来源和储蓄 | 确认经济来源和储蓄；根据经济来源记录储蓄和消费 |
| 4.3 解决问题 | 钱币相关加减法日常应用题（先机械式运算再解题） |

表现标准 1–6：讲述币值/经济来源储蓄 → 解答钱币算式 → 确定算式合理性/记录储蓄支出 → 常规问题 → 多策略常规问题 → 创意非常规问题。

> 备课提示：一年级钱币单元金额规模较小（RM1/RM10以内），二年级起扩大至RM100以内；企业家精神与理财教育跨课程元素在此单元一以贯之。

### 5.0 测量与几何 — 时间与时刻（第47–49页）
**目标**：沟通建构清楚表达情境／思考推理联系表示工艺解决问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 天和月份 | 讲述一天内时刻；依序讲述事件；说出一星期各天、一年各月份名称 |
| 5.2 钟面 | 确认时针分针；确认讲述「半」「一刻」「三刻」；用模拟钟讲出写出「时」「一刻」「半小时」「三刻」 |
| 5.3 解决问题 | 时间相关应用题 |

表现标准 1–6：依序讲述时刻事件 → 说出星期月份名称 → 以时刻讲述写出 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 6.0 测量与几何 — 度量衡（第50–52页）
**目标**：日常生活中对度量衡思考推理沟通探究／用实物建构度量衡概念并应用。

| 内容标准 | 学习标准要点 |
|---|---|
| 6.1 以相对单位测量长度、质量和液体的体积 | 使用相关词汇；用非标准单位测量长度/质量/体积；用非标准单位比较两个以上物体 |
| 6.2 解决问题 | 度量衡相关应用题 |

表现标准 1–6：讲述度量衡词汇 → 测量长度质量体积 → 比较并判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

> 备课提示：一年级仍用「非标准单位」（如手掌、回形针）测量比较，尚未引入米/公斤/升等标准单位（标准单位从二年级起出现）。

### 7.0 测量与几何 — 空间（第53–55页）
**目标**：推理沟通联系表示思考工艺解答情境问题／理解应用空间概念技能／通过立体平面图形珍视鉴赏数学之美。

| 内容标准 | 学习标准要点 |
|---|---|
| 7.1 立体图形 | 说出长方体/正方体/圆锥体/正方棱锥体/圆柱体/球体名称；解说面边顶点；依规律排列；综合制作新模型 |
| 7.2 平面图形 | 说出正方形/长方形/三角形/圆名称；解说直线边角曲线；依规律排列；创作图案 |
| 7.3 解决问题 | 空间相关应用题 |

表现标准 1–6：说出立体平面图形名称 → 讲述特征并依规律排列 → 综合制作模型/设计图案并判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 8.0 统计与概率 — 数据处理（第56–58页）
**目标**：以沟通解说日常数据处理情境／对数据思考推理决策表达想法／运用工艺建构数据处理概念应用数学知识。

| 内容标准 | 学习标准要点 |
|---|---|
| 8.1 收集、分类和整理数据 | 依日常情境收集数据（用记数符号收集简易数据） |
| 8.2 象形统计图 | 读出获取象形统计图资料（一个图代表一个值） |
| 8.3 解决问题 | 数据处理相关应用题 |

表现标准 1–6：说出象形统计图 → 收集数据 → 读出获取资料 → 常规问题 → 多策略常规问题 → 创意非常规问题。

## 各单元表现标准共通结构（备忘）
几乎所有单元的 6 级表现标准都遵循同一套进阶逻辑，方便快速套用出题难度分级：
1. 讲述/说出基本内容
2. 确定/展示/比较（初步操作）
3. 估算/判断合理性/综合建构（含验证意识）
4. 解答日常生活常规问题（单一策略）
5. 运用各种策略解答常规问题
6. 以创意创新方式解答**非常规**问题

这套「1–6级」结构可直接作为分层习题/教案难度设计的骨架，与二至六年级各册一致。
