## 总论重点

**课程宗旨**：让学生具备良好语文能力，能沟通以满足自身需求、获取知识技能信息价值与想法，并建立日常生活中的社交关系。

**九项总体目标**（节录要点）：正确回应指示/口信/提问、以得体态度讲故事讨论发表意见、以正确发音语调朗读并理解显性隐性信息、广泛阅读以丰富词汇培养阅读兴趣、以得体语言记录书写听写信息、创作多种文体写作并编辑修订、欣赏文学作品的语言之美与得体、在口语书写中正确运用语文系统、通过语文活动珍视良好价值观爱国精神与公民意识。

**一年级21项具体目标**：涵盖字母/字音/词语/短语/句子的模仿发音；聆听理解疑问句祈使句并回应；口头传达信息；朗读理解音节词语句子；阅读理解获取词汇与显性信息；朗读故事童谣并演绎；书写字母音节词语短语句子（机械式书写）；根据聚合式/发散式问题造句写作理解性答案；记录信息；听写；创作可控式记叙文/非记叙文；从拼写标点角度编辑修订作品；即兴讲故事；创作朗诵二行/四行马来班顿（Pantun）；唱儿歌；辨识运用普通名词/专有名词/第一二人称代名词/量词、及物动词、性状/颜色/形状形容词、连接词/介词/方位词、前缀衍生词、自由式复合词与完全重叠词、陈述句/疑问句/单句/复句（依语境）。

**六大支柱框架（Kerangka KSSR）**：沟通、精神态度与价值观、人文素质、自我技能、体能与美育、科学与工艺——马来文课程即依此框架编订。

**课程焦点**：低年段（Tahap I：一至三年级）着重听说读写四项基础语文技能的全面掌握；辅以语法（Tatabahasa）系统正确运用、语文之美的欣赏（Aspek Seni Bahasa）。

**21世纪学生素质**（Profil Murid）：善于沟通、思考者、团队精神、坚毅、求知欲强、爱心/关怀、爱国、有原则、掌握信息。

**高层次思维技能 KBAT**：应用、分析、评价、创造——通过思维图、思维导图、高层次提问技巧融入教学。

**教学策略（节录）**：5P概念（联系、渗透、丰富化、补救、评估）为教学基础；补救教学（Pemulihan）与丰富化教学（Pengayaan）依学生程度分层提供材料；解决问题教学法；专题式学习；合作学习；多元智能教学；情境教学；建构主义教学；学习如何学习；未来研究法；自主学习；户外教学；掌握学习（须达80%掌握才可进入下一单元）；探究式学习；模组教学法（Pendekatan Modular，将语文技能拆解为教学模组）；以学生为中心教学法；主题式教学法（列举11项主题：家庭、社会、健康与卫生、安全、团结、文化艺术与美学、身份认同/爱国精神/公民意识、科学技术与创新、环境与绿色科技、农业与畜牧、经济创业与理财管理）。

**跨课程元素 EMK（本版列8项）**：语言、环境永续、良好价值观、科学与工艺、爱国精神、创意与革新、企业家精神、资讯与通讯工艺（TMK）。
> 备注：对比2016年版《二年级》文件的EMK已扩充为10项（新增「全球永续」「理财教育」），本一年级（2015/2016印行）版本尚未列入这两项。

**校内评估 Pentaksiran Sekolah（PS）**：由任课教师规划、实施、记录并汇报，持续以形成性＋总结性方式进行；依据「标准参照评估」（Pentaksiran Rujukan Standard），不与其他学生比较，只依标准描述学生个人进展。文件列出语文能力总体1–6级「掌握程度」诠释表（Jadual 3）：1非常有限 → 2有限 → 3满意 → 4良好 → 5非常好 → 6卓越（能成为其他学生的典范）。

## 5 个语文技能模组摘要

### 1.0 聆听与说话技能 Kemahiran Mendengar dan Bertutur（第28页）
**说明**：聆听技能指学生仔细聆听、理解并领会所听内容并作出回应的能力；说话技能指学生运用正确发音语调、得体礼貌地建立关系与传达信息意见感受创意批判想法的能力，并强调语法正确运用。

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 聆听并作出回应 | 模仿并说出字母名称/字音；模仿说出含元音/辅音/双元音/复合元音/二合字母/复合辅音的字词短语句子；聆听理解并回应含疑问词的问句与祈使句 |
| 1.2 为各种目的说话以传达信息与想法 | 以正确发音语调、得体地传达口信；传达资料中的显性信息 |

**表现标准 1–6**：对各类问句/祈使句/口信/显性信息的回应，从「发音语调正确但得体程度非常有限」逐级进阶至「非常详尽、一致，成为示范」。

### 2.0 阅读技能 Kemahiran Membaca（第30页）
**说明**：阅读技能指学生以正确发音、语调、停顿与流畅度阅读的能力，着重理解与批判性推敲多种材料，并能对所读文本有所领会。

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 基础阅读与理解 | 以正确发音语调朗读音节／词语／句子；朗读并理解词语／短语／段落中的句子 |
| 2.2 阅读理解并推敲图文与非图文材料 | 阅读理解推敲以获取一般词汇与显性信息 |
| 2.3 阅读并欣赏文学与非文学作品 | 以正确发音语调朗读文学作品（故事、班顿Pantun）并全情演绎；朗读非文学作品（如标签label）并演绎 |

**表现标准 1–6**：阅读理解推敲材料、领会文学与非文学作品并演绎，从「非常有限」逐级进阶至「非常详尽、一致，成为示范」。

### 3.0 书写技能 Kemahiran Menulis（第32页）
**说明**：书写技能指学生书写词语、透过多种文体表达与个人经验及知识相关的想法的能力，注重合乎语法的句子、正确标点拼写、字迹整洁清晰，并鼓励创意书写。

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 基础书写 | 机械式书写：字母／音节／词语／短语／句子 |
| 3.2 书写有意义的词语、短语、句子 | 造句并书写词语／短语／句子；根据聚合式／发散式问题造句写理解性答案；记录某事项信息；听写词语／短语 |
| 3.3 完成写作作品 | 以可控方式创作记叙文与非记叙文；从拼写、标点角度编辑修订作品 |

**表现标准 1–6**：机械式书写、造句、写理解性答案、记录信息、听写、创作记叙/非记叙文、编辑修订，从「非常有限」逐级进阶至「非常详尽、一致，成为示范」。

### 4.0 语文之美 Aspek Seni Bahasa（第35页）
**说明**：涉及马来文语言之美与得体特质的理解与掌握，包含理解、表达与领会语文之美的能力；透过本模组学生能创作并展示多种体裁的创意作品（口头与书面），并以"寓教于乐"（didik hibur）方式呈现。

| 内容标准 | 学习标准要点 |
|---|---|
| 4.1 在文学作品中运用语言之美与得体元素 | 以正确发音语调即兴讲故事 |
| 4.2 领会文学作品中语言之美与得体 | 以适当发音语调领会二行／四行班顿（Pantun）之美；以正确发音语调演唱儿歌旋律 |
| 4.3 创作融入语言之美与得体的文学作品并创意展示 | 以半可控方式创作并展示二行／四行班顿 |

> 备注：本模组的聆听说话/阅读/书写技能评估可并入其他三大技能一并实施，但教学仍以模组化方式进行。

### 5.0 语法 Aspek Tatabahasa（第36页）
**说明**：涉及马来文构词法（Morfologi）与句法（Sintaksis）的理解与掌握，须透过有计划、技巧适当有效的教学，使学生能在口语与书面语的各种语境中正确精准运用语法。

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 理解并依语境运用词类 | 辨识运用普通名词／专有名词／第一二人称代名词／量词；及物动词；性状／颜色／形状形容词；连接词／介词／方位词（依语境） |
| 5.2 理解并依语境运用构词法 | 辨识运用前缀衍生词；自由式复合词；完全重叠词（依语境） |
| 5.3 理解并依语境造句 | 辨识运用陈述句／带疑问词疑问句；单句／复句（依语境） |

> 备注：本模组评估同样可并入其他三大技能一并实施，教学仍以模组化方式进行。

## 表现标准共通结构（备忘）
各模组的 6 级表现标准均遵循同一套「语文能力总体掌握程度」进阶逻辑（Jadual 3 通用诠释），可直接作为分层习题/教案难度设计骨架：
1. 发音语调等基本技能表现「非常有限」，需大量指导、示范与练习
2. 表现「有限」，需少量指导与练习
3. 表现「满意」，能表达想法并掌握基础思维技能，无需指导
4. 表现「良好」，能有效运用语文知识、批判思维，具最低限度自主学习
5. 表现「非常好」，能清晰详尽表达、有效沟通、掌握较复杂语文知识与批判创意思维、能自主学习
6. 表现「卓越」，清晰详尽有条理表达、掌握批判创意革新思维、充满自信有效沟通、完全自主学习，并成为其他学生的示范楷模

这套「1–6级」结构与数学科表现标准的分级逻辑（讲述→操作→判断合理性→常规问题→多策略→创意非常规）性质不同，马来文着重「语文能力整体掌握程度」的质性描述，适合用于口语/书面语表达类习题的难度分层设计。
