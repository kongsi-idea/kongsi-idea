## 10 个课题摘要（五年级）

### 生命科学
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 2.1 人体的骨骼系统 | 讲述主要骨骼功能（脊柱支撑身体/头骨保护头脑/肋骨保护内脏/四肢骨支撑移动）；确认骨骼关节位置；说出关节功能 |
| 2.2 人体的血液循环系统 | 讲述心脏肺血管的功能；绘制血液循环途径示意图；总结循环系统的重要性 |
| 2.3 人体系统之间的关联 | 举例解释系统间关联（消化系统阻塞影响呼吸系统等）；推论照顾人体所有系统的重要性 |
| 3.1 动物的物种生存 | 说出物种生存定义；解释举例动物外形特征/特殊本能自卫、适应恶劣气候；确认保护卵与幼儿的方法 |
| 3.2 设计与制作动物模型 | 想象创造能自卫适应气候的动物模型；推论该模型特征 |
| 3.3 生物之间食与被食的关系 | 说出食物链定义；确认生产者消费者；从能量流动角度总结光合作用与食物链关系；绘制食物网；预测食物网变化的影响 |
| 4.1 植物物种的生存 | 解释举例植物特有特征保护自己远离天敌、适应气候季节转换 |
| 4.2 种子或果实的传播 | 说出植物传播种子/果实方法；联系种子果实特征与传播方法；预测传播方法 |

### 物理科学
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 5.1 电源 | 解释举例电的来源 |
| 5.2 串联电路和并联电路 | 确认灯泡排列方式；利用元件符号绘制电路图；比较串并联电路灯泡亮度；改变灯泡/电池数量做实验 |
| 5.3 安全使用电器和节省电源 | 针对影响电量消耗因素作出见解；解释错误使用电器后果；讲述安全用电措施；分析电费单所消耗电能 |
| 6.1 热和温度 | 说出热和温度定义；正确使用工具单位测量温度；观察冰块加热确定冰点沸点；讲述材料受热散热情况（膨胀收缩） |

### 材料科学
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 7.1 生锈 | 说出生锈物品特征；概括铁制品会生锈；实验确认导致生锈的因素；讲述防锈方法 |
| 8.1 物质的形态 | 说出固液气三态；依形态分类材料；列出三态特征；概括水能以三种形态存在 |
| 8.2 水的形态变化 | 讲述水的形态变化；解释举例受热散热时形态变化；联系水的形态变化与云雨形成 |

### 地球与宇宙
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 9.1 月相 | 说出月球本身不发光而反射太阳光；讲述月球自转公转方向周期；描绘月相依阴历运转周期 |
| 9.2 星座 | 确认星座图形（猎户座/北斗七星/南十字座/天蝎座）；说出星座用途 |

### 工艺
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 10.1 生活中所使用的工具 | 说出工具用途；解释工具结合简单机械原理操作；推论工具中简单机械组合的重要性；评价优质工具特征（材料/寿命/保养/成本/环保/安全） |

## 与前四年级对照的年级递进重点（备忘）
- 生命科学从"体内系统"（四年级）扩展到"物种生存策略、食物链食物网的能量流动"等生态学概念
- 物理科学首次系统涉及"电路安全应用（含电费分析）""热胀冷缩""物质三态变化"等生活应用型概念
- 地球与宇宙从"地心引力/自转公转"（四年级）延伸到"月相/星座"等天文观测主题
- 工艺课题从"杠杆/简单机械原理"（四年级）综合应用到"评价生活工具设计优劣"（五年级）
