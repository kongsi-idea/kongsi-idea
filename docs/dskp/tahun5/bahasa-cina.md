## 5 个语文技能模组摘要（五年级）

### 1.0 听说技能
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 1.1 进行口语交际 | 1.1.1 **针对话题参与讨论**，理解别人说话并说出自己的意见（较四年级新增"参与讨论"）；1.1.2 针对话题提出问题，正确应用疑问代词 |
| 1.2 聆听口语和书面语 | 1.2.1 **专注耐心**聆听，边听边记边想，**辨别内容主次**（新增辨别主次要求）；1.2.2 正确把握中心思想，辨别内容主次 |
| 1.3 进行口头表达 | 1.3.1 讲述事情并说出自己的**看法和感受**；1.3.2 **说明事理**，要求说明清楚条理分明（较四年级"说明活动/步骤"提升为"说明事理"） |

### 2.0 阅读技能
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 2.1 阅读与理解教材 | 2.1.1 借助工具书掌握词语、理解句段篇内容，**初步掌握其主题思想**（新增主题思想概念） |
| 2.2 朗读教材，感悟其内容 | 2.2.1 语音正确字句完整语速语调适当，情感自然，**态度自信**（新增自信要求） |

### 3.0 书写技能
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 3.1 应用铅笔写字 | 3.1.1 书写楷书，**注意手写体楷中带行、点画牵连的特点，以提高书写速度**（较四年级更强调速度与连笔） |
| 3.2 培养书面表达能力 | 3.2.1 习写段落练笔，尝试用适当手法写出人物/事物局部特点；3.2.2 习写日记**和私函**（新增私函文体）；3.2.3 进行书面表达，**能够有重点地分段表述**（较四年级新增"分段表述"要求） |

### 4.0 趣味语文
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 4.1 进行各类语文游戏 | 4.1.1 以有趣形式积累扩展词汇，操练语音 |
| 4.2 背诵古诗 | 4.2.1 背诵古诗十首 |
| 4.3 诵读和演绎教材 | 4.3.1 语音正确、语调恰当、生动自然有感情 |
| 4.4 分享阅读心得 | 4.4.1 针对所阅读材料，找出话题与人分享 |
| 4.5 习写毛笔字 | 4.5.1 **使用毛笔临摹**名家楷书字帖（较四年级"仿影"进阶为"临摹"） |

### 5.0 语文基础知识
| 内容标准 | 五年级学习标准要点 |
|---|---|
| 5.1 掌握汉字基本知识 | 5.1.1 汉字演变基本知识，加强识记 |
| 5.2 学会汉语拼音 | 5.2.1 正确认读"啊"的音变**和"轻声"与"儿化"**（较四年级新增轻声、儿化知识） |
| 5.3 认识各类词语 | 5.3.1 认识量词、近似字、多音字，辨析理解词义 |
| 5.4 认识不同类型的句子 | 5.4.1 认识不同类型句子，了解关联词语在句中作用并正确使用 |
| 5.5 认识各种标点符号 | 5.5.1 **省略号和破折号**的使用（较四年级分号着重号连接号更进阶） |
| 5.6 认识基本的修辞手法 | 5.6.1 认识修辞手法（比喻、夸张、比拟、反复、引用等），体会文章表达效果 |

> 备注：趣味语文、语文基础知识均不另设评价标准。

## 年级递进重点（备忘）
- 口语交际从"敢于说出感受"（四年级）→"参与话题讨论并说出意见"（五年级）
- 书面表达首次要求"有重点地分段表述"，文体新增私函
- 毛笔字从"仿影"（四年级）→"临摹"（五年级），书写自主度提高
- 标点符号、语音知识（轻声/儿化）持续递进加深
