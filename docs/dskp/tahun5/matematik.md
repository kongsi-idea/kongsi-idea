## 8 个学习单元摘要（沿用四年级架构：整数与基本运算合并、坐标比比例合并；五年级钱币单元新增贷款负债管理、数据处理单元新增众数中位数平均数极差）

### 1.0 数与运算 — 整数与基本运算（第29–34页）★首次引入质数、括号混合运算
**目标**：认识理解应用1000000以内整数与基本运算概念程序／应用知识技能解答问题／正确数学语言／推理联系表示沟通工艺。

| 内容标准 | 学习标准要点 |
|---|---|
| 1.1 数值 | 讲述1000000以内数目（读/说/写）；确定数值（数位数值分析、比较、顺逆序排列/完成数列）；笔记强调正确读法（如382425读作三十八万二千四百二十五） |
| 1.2 质数 | 确认100以内的质数（只能被1和本身整除的数） |
| 1.3 估算 | 依参照物估算并确定合理性 |
| 1.4 近似值 | 找出整数至十万位的近似值；确认已写成近似值的可能数目（可涉及小数百分比钱币度量衡） |
| 1.5 有规律的数列 | 顺逆序一至十个、百个、千个、万个、十万个排列规律数列（涉及至6个数目） |
| 1.6 基本运算 | 至五数六位数以内加法（和1000000内）；至三数减法；六位数以内与二位数/100/1000的乘法（积1000000内）；除法 |
| 1.7 混合运算 | 1000000以内有括号和无括号的混合运算（加乘/减乘/加除/减除组合，先从不进位借位开始，可涉及钱币） |
| 1.8 未知数的应用 | 只乘一次乘法算式中确定未知数值（积至1000000）；确定除法算式未知数（用字母表示，未知数可在三种不同位置） |
| 1.9 解决问题 | 整数、基本运算、混合运算相关应用题；只有一个未知数涉及乘除法的应用题 |

表现标准 1–6：读算式 → 确认质数/解说运算混合运算程序 → 确定数值(估算近似值/完成数列)/解答判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 2.0 数与运算 — 分数、小数与百分比（第35–38页）★首次出现分数乘法、超过100%的百分比
**目标**：联系分数小数百分比与日常生活／应用知识技能解答问题／推理联系表示探究沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 2.1 分数 | 两数分数乘法运算（涉及整数、真分数、带分数；分母至10） |
| 2.2 小数 | 找出至三位小数的近似值（可涉及钱币度量衡）；至三位小数加减混合运算；乘二位数/100/1000；除法（商至三位小数） |
| 2.3 百分比 | 带分数化百分比或反之；从100%以内和超过100%的百分比中计算数量或反之（用百格图折纸） |
| 2.4 解决问题 | 分数小数百分比相关应用题 |

表现标准 1–6：读算式 → 分数带分数百分比换算/找小数近似值 → 分数乘法/小数运算判断合理性/百分比计算数量 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 3.0 数与运算 — 钱币（第39–42页）★首次引入单利复利、贷款负债管理
**目标**：钱币与日常生活联系／应用理财教育知识技能／推理探究钱财使用／钱财沟通联系解决问题／**展现并实践企业家精神**。

| 内容标准 | 学习标准要点 |
|---|---|
| 3.1 钱币的基本运算 | 至三币值加法（和至RM1000000）/减法（差RM1000000内）；与二位数/100/1000乘法（积至RM1000000）/除法 |
| 3.2 钱币的混合运算 | RM1000000以内有括号和无括号混合运算（加乘/减乘/加除/减除） |
| 3.3 储蓄和投资 | 说明储蓄投资意思；说明单利储蓄和复利储蓄意思（笔记：介绍投资股息红利、说明储蓄投资增值降值） |
| 3.4 贷款和负债管理 | 说明贷款负债意思；说明贷款与现金购物差价（笔记：贷款是便利设施；说明利息角色；信用卡使用是负债原因） |
| 3.5 解决问题 | RM1000000以内钱币相关应用题 |

表现标准 1–6：讲述储蓄投资意思 → 说明单利复利 → 完成钱币算式判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

> 备课提示：五年级钱币单元是六年制中理财教育纵深最深的一站——单利复利计算、贷款负债概念、信用卡使用风险意识首次系统出现，教案宜结合实际储蓄利率情境和「借贷≠白得」的价值观讨论。

### 4.0 测量与几何 — 时间与时刻（第43–46页）★首次出现闰年、涉及分数小数的时间单位换算
**目标**：应用知识技能解答时间与时刻问题／推理联系表示工艺解答问题／有效管理时间。

| 内容标准 | 学习标准要点 |
|---|---|
| 4.1 相隔时间 | 确定相隔时间（天和小时；月和天；年、月和天，笔记：介绍闰年，(ii)(iii)项只以天计算） |
| 4.2 时间单位之间的关系 | 涉及分数的时间单位换算（小时↔分钟、天↔小时、年↔月、年代↔年、世纪↔年代/年）；涉及小数的同类换算（答案需以整数写出，分数只涉及较大单位） |
| 4.3 时间的基本运算 | 换算/不换算单位的分数时间加减法；小数时间加减法（各类单位组合） |
| 4.4 解决问题 | 时间与时刻相关应用题 |

表现标准 1–6：讲述相隔时间 → 换算分数小数时间单位 → 解答分数小数时间加减法判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 5.0 测量与几何 — 度量衡（第47–51页）★首次引入涉及分数小数的度量衡换算与四则运算
**目标**：应用知识技能解答度量衡问题／推理联系表示探究沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 5.1 长度 | 涉及分数/小数的毫米厘米、厘米米、米公里换算；至三个分数小数长度加减法（换算/不换算单位）；与二位数/100/1000乘除法 |
| 5.2 质量 | 涉及分数小数的克公斤换算；至三个分数小数质量加减法；乘除法 |
| 5.3 液体的体积 | 涉及分数小数的毫升升换算；至三个分数小数体积加减法；乘除法 |
| 5.4 解决问题 | 度量衡相关应用题 |

表现标准 1–6：换算分数小数度量衡单位 → 说明算式步骤 → 完成算式判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 6.0 测量与几何 — 空间（第53–55页）★首次出现综合图形/综合立体周长面积体积
**目标**：应用知识技能解答空间问题／通过棱柱体非棱柱体组成图形珍视鉴赏数学之美／推理联系表示沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 6.1 正多边形 | 以边、角、对称轴、角度、对角线讲述正多边形特征（笔记：介绍内角） |
| 6.2 角度 | 测量至八边正多边形的角度（只测内角，用量角器） |
| 6.3 周长和面积 | 确定两个至八边正多边形组成的综合图形周长（含直角三角形/等腰三角形/长方形）；确定两图形组成综合图形面积（长方形/正方形/等边三角形/等腰三角形/直角三角形） |
| 6.4 立体的体积 | 确定两图形组成综合立体（正方体长方体）的体积 |
| 6.5 解决问题 | 空间相关应用题 |

表现标准 1–6：说出综合图形名称 → 解说测量角度步骤 → 测量角度/计算综合图形周长面积体积 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 7.0 联系与代数 — 坐标、比与比例（第57–59页）★首次出现坐标间横直向距离、三类比（部分比部分/部分比整体/整体比部分）
**目标**：应用知识技能解答坐标比比例问题／珍视鉴赏数学之美／推理联系表示沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 7.1 第一象限的坐标 | 确定两坐标之间的横向和直向距离 |
| 7.2 比 | 以a:b表示两数量之比（部分比部分/部分比整体/整体比部分，比的单位须相同） |
| 7.3 比例 | 以比例确定未知值（含归一法） |
| 7.4 解决问题 | 坐标比比例相关应用题 |

表现标准 1–6：讲述x轴y轴位置/说出比 → 说明确定横直向距离步骤/表示比 → 解答坐标距离/比的问题判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

### 8.0 统计与概率 — 数据处理（第61–63页）★首次出现众数、中位数、平均数、极差
**目标**：掌握从饼分图获取资料的技能／应用知识技能解决数据处理问题／作决策提想法解说日常情境／推理联系表示沟通工艺解答问题。

| 内容标准 | 学习标准要点 |
|---|---|
| 8.1 饼分图 | 诠释饼分图（用剪报/杂志/期刊/报告中的饼分图） |
| 8.2 众数、中位数、平均数和极差 | 从非分组数据中认识确定四者（涉及象形统计图/条形统计图/饼分图） |
| 8.3 解决问题 | 数据处理相关应用题 |

表现标准 1–6：讲述众数中位数平均数极差意思 → 说明诠释数据步骤 → 解答诠释数据问题判断合理性 → 常规问题 → 多策略常规问题 → 创意非常规问题。

## 各单元表现标准共通结构（备忘）
与一至四年级一致的六级进阶逻辑：
1. 讲述/读出基本内容
2. 说明步骤/换算/初步操作
3. 完成算式/测量/判断合理性（含验证意识）
4. 解答日常生活常规问题（单一策略）
5. 运用各种策略解答常规问题
6. 以创意创新方式解答**非常规**问题（钱币/时间/坐标比比例/数据处理单元原文表现标准第6级仍写作「常规问题」，疑为官方文件笔误，教学时按惯例理解为非常规问题）
