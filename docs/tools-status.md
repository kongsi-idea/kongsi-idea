- 问“哪些做到一半”：筛选“开发状态＝开发中／暂停”。

   ```bash
   cd /Users/yquanloo/Documents/my-agent/teaching-tools
   npm run status:sync
   ```

2. 脚本会自动扫描所有 `tahun*` 目录；新目录即使尚未登记 Hub，也会进入本表并标成“开发中／待评估”。

   - 本文件；
   - `teaching-tools/README.md` 已上架清单；
